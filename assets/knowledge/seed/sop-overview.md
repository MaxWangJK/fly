# 外贸SOP总览

外贸工作不是把所有客户都推进同一个节奏，而是在每个阶段明确「已知什么、还缺什么、下一步由谁完成」。一套好的SOP应帮助你少遗漏、快交接，也允许你根据产品和市场做出判断。下图式流程可从资料库的“SOP地图”逐步进入对应主题。

## 从线索建立判断

1. 记录线索来源、国家和主营业务，先排除明显不匹配的对象。
2. 核对公司身份、采购角色和可公开验证的经营迹象。
3. 按潜力与当前意向分层，不把所有联系人都当作立即成交客户。

:::tip
每个阶段只要求足以推动下一步的信息。不必在第一封消息里完成全部调查。
:::

## 从沟通推进到报价

先确认应用场景、规格、数量、目的港或交付方式，再说明产品价值与边界。报价不仅是一张价格表，还应交代有效期、贸易术语、包装、交期和待确认事项。发送后记录客户反馈，并约定合适的后续动作。

## 从订单执行走向复购

确认PI与收款条件后，再协调生产、质量、包装、单据和出运。各节点留存版本和责任人；出现变更时先确认影响，再更新承诺。交付完成后回访实际使用情况，复盘问题，寻找下一次合作的合理机会。

:::warning
SOP是提醒和核对工具，不应替代合同、法律或报关专业判断。关键交付承诺应以双方确认的文件为准。
:::

## 本周可执行的检查清单

- [ ] 为高优先级客户写下一个明确的下一步。
- [ ] 对即将到期的报价确认客户是否收到并理解。
- [ ] 核对在执行订单的下一里程碑、负责人和日期。
- [ ] 记录一次成交或输单中的可复用经验。
