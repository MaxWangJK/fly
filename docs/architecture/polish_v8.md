# Fly Polish V8

## 范围

本轮只处理 Today 日期语义、四象限创建时间、分类设置中心和一级导航显隐。不迁移数据库、不修改装柜算法，不删除已有业务数据。

## 日期规则

`taskTodayPredicate` 是 Task Today 和 Dashboard 今天任务的共同 SQL 条件。按本地日历构造当天零点和次日零点，避免用固定 24 小时推算跨夏令时日期。

- 双端日期：开始时间早于次日零点，截止时间不早于今天零点。
- 单端日期：存在的日期落在当天半开区间内。
- 无日期、已删除、状态完成或 completedAt 有值的任务均排除。
- UTC 时间按同一时刻与本地边界比较；不截取 UTC 的年月日作为本地日期。
- 保留原有其他任务集合与日历视觉。

四象限通过 RelativeDateFormatter.createdAt 展示本地创建时间，使用 11px 次要文字、第二行靠右，保留标题宽度和原完成样式。

## 设置与导航

分类：常规、外观、导航、提醒、数据与备份、文件与存储、导入与导出、关于。桌面分类栏宽 200px，右侧内容最大 740px；窄窗口切换顶部分类选择器，沿用当前主题。

复用现有提醒、备份、真实数据迁移、客户 Excel 导入与 Excel 导出，不新增平行业务实现。

AppSettings 的 navigationVisibility JSON 原子保存 dashboardVisible 和 crmVisible。CRM 开关同时管理客户与订单；默认都显示。失败时保留原值并显示错误，不改业务表。

启动先等待导航配置读取；统一 StartupWorkspaceResolver：Dashboard → 客户今天 → 任务今天。没有新增上次工作区恢复。路由守卫也使用此规则处理隐藏中的页面、深链接和隐藏后切换。任务、日历、四象限、工具、设置保持可访问。
