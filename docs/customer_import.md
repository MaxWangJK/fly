# 新建客户中的简单 Excel 导入

2026-11-09，build57之后的源码续补：按最新要求，客户Excel导入、模板和数据导出仅在电脑端提供；Android/iOS隐藏相关入口，包括手机横屏和平板布局。电脑点击客户“+”，在新建客户弹框底部选择“批量导入”或“Excel 模板”。下载模板保留正在填写的单个客户草稿；批量导入成功后关闭原空白创建框、选中首个导入客户，沿用列表刷新与筛选恢复，不额外创建草稿客户。

电脑保存模板到所选路径。手机仍可正常创建单个客户，查看电脑导入后同步来的客户；文件管理的添加文件、图片、拍照及分享继续保留。模板只有一个工作表和以下表头，没有示例客户：

| 列 | 填写规则 |
| --- | --- |
| 客户名称 * | 必填 |
| 国家 * | 必填 |
| 客户级别 * | 必填，填写已有级别，例如 A、A级或当前自定义级别名 |
| 客户状态 * | 必填，只接受新客户、开发中、意向客户、成交客户、复购客户 |
| 客户来源 | 可选，支持已有来源或新名称 |
| 公司 / Email / Phone / 通讯账号 / WhatsApp / 备注 | 可选；实际模板保留与新建客户对应的联系方式列 |

使用模板直接进入预览与重复检查；旧表仍可选工作表并手动匹配列。预览显示有效、无效、可能重复数量和行号原因，空白行忽略；用户确认后导入。重复处理保留跳过或覆盖选项，同文件重复也检查。覆盖时空白可选列不清空已有值，原创建时间不变，版本和业务同步待发送记录正常更新。

导入复用现有客户仓库与级别标签，不把客户写成任务，不改变同步协议，不向匿名统计发送客户内容。每行独立事务，某行失败不会留下半个客户；结果说明成功、跳过与失败。大量文件仍需用户用实际资料副本验收，自动测试使用隔离库和临时 XLSX。

2026-11-12：上述最新规则已随Windows/Android2.0.22+58测试包交付，详见[安装包与核验](release/fly_2_0_22_build58.md)。
