# 清朗商务配色（可选）

参考用户提供的浅色 B 端界面截图，提取的是信息层级与配色原则，不复制其布局、插画或数据。此方案保留 Fly 现有导航与交互，其他主题及已保存的主题偏好不变。

## 视觉规则

- 灰白分层：画布 `#F5F7FB`、侧栏 `#EDF1F7`、导航轨 `#F8FAFC`、卡片与编辑面 `#FFFFFF`。依靠表面差异和细边框区分区域，不把整页染成同一种颜色。
- 深紫 `#493B82` 仅用于导航、选中与主操作；青绿 `#087E74` 用于正向数据和首页焦点卡。警告与错误仍保留独立语义色。
- 文字层级：正文 `#25243B`，次要信息 `#647083`。在白色表面上两者满足常规文字对比度要求。
- 文件中等/小图标视图采用白色轻边框卡片；笔记目录、列表与编辑面分层。列表视图仍保持紧凑，不改成宽松卡片表格。
- Dashboard 在此主题下先显示五项真实业务指标，再显示“当前工作分布”的数量对比，最后展示待处理明细。对比图只使用当前查询结果，不捏造历史趋势或增长率。

## 使用与兼容

设置 → 外观 → 清朗商务。原主题保持可选，用户的选择继续保存为 `colorPalette`；没有数据库结构变更。深色模式使用协调的紫色点缀，不强制切回浅色。
