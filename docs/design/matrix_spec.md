# Matrix Specification V2

The Matrix is a stable 2 × 2 layout:

1. Important and urgent — restrained red
2. Important, not urgent — restrained orange
3. Urgent, not important — restrained blue
4. Not important, not urgent — restrained green

Quadrant color is limited to a 3 px top accent, heading, selection line, and drop feedback. Cards remain white with low-contrast borders. Each quadrant has its own scroll bar and compact inline quick add. All tasks, including completed tasks, remain visible; completion uses the shared checkbox and struck-through title. Direct drag and drop persists `importance` and `urgency` immediately.
