# Fly 整体视觉更新 — build22

> 已撤回：用户要求恢复 build21。本文件仅保留历史设计记录，当前源码已恢复 build21 的主题及页面样式。

本轮保留所有业务流程、布局结构、存储和快捷键，调整全局主题、模块强调色及内容面板。

## 配色原则

使用清晰的表面层次：导航轨 → 文件夹/二级侧栏 → 浅色工作台 → 内容卡片/纸张。强调色用于选中、按钮、图标和小面积标记。文件、笔记主内容保留高可读性的中性底色。

设计参考（采用层次和低饱和配色思路，非直接复制完整主题）：

- [Material 3 表面颜色角色](https://docs.flutter.dev/release/breaking-changes/new-color-scheme-roles)
- [Nord 色板](https://www.nordtheme.com/docs/colors-and-palettes/)
- [Catppuccin 色板](https://catppuccin.com/palette/)

## 页面设计

| 模块 | 强调方向 | 页面层次 |
| --- | --- | --- |
| Dashboard | 指标对应青绿、蓝、琥珀 | 白色指标卡、微弱渐层和小图标底色 |
| 客户 | 青绿 | 中性列表、青绿选中与标签筛选边框 |
| 订单 | 蓝 | 中性内容、蓝色选中、独立状态/风险语义色 |
| 任务 | 当前主题强调色 | 完成、悬停、选中背景全部跟随当前主题 |
| 日历 | 靛蓝 | 保留连续日历网格，以现有主题表面和轻强调区分状态 |
| 四象限 | 土色导航、各象限语义色 | 各象限加入极浅语义色底，保持色条和标题 |
| 今日复盘 | 四个语义色区块 | 保留四区结构，加入细边界与中性输入框 |
| 文件 | 蓝灰 | 浅工作台、白卡片、柔色文件图标底、独立预览底色与顶部工具栏 |
| 笔记 | 柔紫 | 文件夹栏、独立笔记卡片列表、带细边框和轻阴影的纸张编辑区 |
| 工具 | 琥珀 | 工具导航和操作强调统一，3D 场景继续使用专用深底 |
| 设置 | 当前主题 | 主题选项新增色板预览和说明，便于比较 |

模块色与主题色混合；纯白极简的混合比例更低，保持克制。用户定义的标签、状态与货物颜色继续保持其业务含义。

笔记标题和块编辑器取消继承的输入框边界，保留原编辑、媒体、标签和保存逻辑。文件导入、拖出、列表模式、图标模式、预览和关联跳转流程保持。
