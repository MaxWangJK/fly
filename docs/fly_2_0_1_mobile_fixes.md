# Fly 2.0.1+37 手机与同步修复

交付补充（2026-10-14）：本阶段改动已合并到 2.0.2+38 功能测试包；最新产物及验证见 [发布记录](release/fly_2_0_2_build38.md)。以下保留当时的实现与验收记录。

## 操作变化

- 手机任务标题旁提供日历和四象限入口；底部为客户、订单、任务、文件、更多。首页、笔记、工具进入更多，电脑导航沿用原布局。
- 手机横屏保留紧凑布局。日历点击日期后在下方查看完整任务列表，长列表可滚动；四象限横屏可以滚动到下面两个象限，并能新建任务。
- 手机设置采用全屏分类列表，点击进入常规、外观、同步等页面，再通过返回按钮回到分类。
- 同步仅有云同步和电脑与手机同步两种连接方式，同一时刻运行一种。电脑启动服务后显示五分钟有效的二维码，手机扫码配对后弹出连接结果。
- 默认填写 `world-workshop.cn/api`，内部使用 HTTPS。自建可以填写 `192.168.0.21/api`、`192.168.0.21:8765/api` 或域名；测试连接会尝试适用的 HTTP/HTTPS，并保存连接成功的协议。显式填写协议仍兼容。
- 局域网自动双向同步实体文件。自建云服务器自动传文件；官方地址普通账号只同步文件信息，只有 `max@ceiling-arts.com` 同步实体文件。服务端部署配置见 `server/README.md`。
- 手机文件通过系统文件应用打开；缺少查看器时说明原因。导入使用选择器返回的内容流，照片导入到 Fly 的持久文件目录后再同步，不依赖临时图片地址。
- 手机文件目录新增拍照上传。取消拍照不导入；拒绝相机权限会显示错误；Android 回收拍照活动后支持恢复已拍照片到文件收件箱。

## 数据与兼容

云同步与局域网各保存独立的版本、游标、待上传请求和冲突，切换时保留本地业务数据和文件，并将当前修改排入所选模式的队列。一个数据目录仍仅连接一个云端账号/服务器和一个电脑工作区，以防不同账号混用数据。切换方式之后需开启对应服务或同步开关。

旧版默认关闭文件内容同步，这次依据上述规则自动启用。已同步的文件信息在下一轮同步时补下载实体文件。对端文件尚未上传时显示等待内容，不阻断其它文件下载。

1.0 程序和主分支不变；本次更新在 2.0 分支。更新客户端前建议备份数据。安卓 APK 沿用测试签名，Windows 使用完整解压包。

## 验证范围

回归覆盖：无普通文件路径的图片内容导入、Windows 旧路径兼容、约 20 MiB 实体文件双向传输、扫码内容及过期检查、官方账号文件规则、服务端所有实体文件接口权限、两种模式切换保留待上传修改，以及 390×844 和 844×390 手机布局。

扫码相机、系统相机和手机外部查看器的实际运行，仍需安卓实机验收；Windows 环境不代表 iOS 验收。

2026-10-13 验证结果：代码分析无问题，客户端全套 290 项通过；全套跳过的两客户端云端测试另启本机临时服务器执行通过，共 291 项。后端 16 项通过。Windows 与 Android 2.0.1+37 均完成构建；Windows 压缩包完整性、安卓版本/设备架构和沿用的测试签名已核验。安装包及测试步骤在 `dist/README-Fly-2.0.1-build37-testing-20261013.md`。
