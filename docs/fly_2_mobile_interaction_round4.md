## 文件多选和批量操作

- 文件工具栏增加“多选”；也可在长按菜单点“选择”。勾选文件或点“全选”，底部持续显示“已选 N 项”，可批量分享、删除、取消。
- 全选范围为当前文件夹或集合、搜索和标签筛选的结果。切换位置或筛选、修改搜索会清空选择，避免操作隐藏文件。切换相册/列表保留当前选择。
- 分享调用系统面板并传递实际文件；同名文件生成不同的分享文件名，避免 Android 接收方只得到最后一个同名文件。显示名称没有扩展名时补上原扩展名。
- 任一选中文件尚未下载或已删除，整批分享会给出原因，不悄悄遗漏文件。复制期间展示进度并防止重复点击。
- Android/iOS 在分享完成回调后清理 Fly 临时副本；无法获得完成回调的平台（包括 Windows）保留副本供接收方读取，下次分享时清理超过一天的副本。永久删除同时清理该文件的 Fly 分享副本；系统或接收应用的外部副本仍由其所在应用管理。
- 删除会先确认数量及关联附件。一般删除进入“最近删除”；永久删除清理实体、缩略图、下载分片和无其他引用的同步内容。部分失败逐项保留未完成选择，并提示成功/失败数量。批量永久删除避免对旧删除记录逐项重复全量扫描。

## 显示偏好与清单路径

- 在本机保存相册/列表等视图、排序、图片或文件优先、子目录开关、文件标签、客户标签，以及最后进入的集合/文件夹。
- 首次手机使用相册、图片优先；电脑首次使用列表。手机和电脑的显示偏好分开保存，不通过业务同步覆盖对方。
- 无效的旧偏好使用默认值；已移除的标签不再应用，失效文件夹回到根目录。直接打开指定文件时绕过文件标签筛选，避免被上次筛选隐藏。
- 选中多级清单后显示简短路径，例如“Work project / Deliveries”；较深层级显示最后三层，完整路径可通过提示查看。

## 同步状态详情

- 手机同步按钮旁增加详情入口；同步设置页面也展示同一状态信息。
- 显示待发送记录数（同一记录多次编辑合并计数）、待发送/确认文件数、待下载文件数、等待源设备提供内容的数量。
- 文件传输显示当前文件、检查数量及字节进度；上传进度来自服务端已确认的分片，下载进度来自实际接收的内容。文件校验成功后才确认可用。
- 展示当前同步空间的最近成功时间和失败原因，切换服务器不会误用旧连接的时间。连续三次失败停连后可以再次连接。状态面板打开时定期更新，进入后台或关闭后停止刷新。
- 明确说明绿色仅表示连接或同步周期成功，不承诺全部实体文件已经到本机。服务器/账号不允许文件同步时单独说明限制；记录仍可正常同步。
- 队列依据当前同步空间、文件记录、本机文件是否存在/大小及已确认的内容状态判断。新远端版本已到记录、旧实体仍在本机时计入待下载；同步周期会进一步计算完整哈希并处理同大小的外部编辑。

## 手机日历

- 仍然只有周、月两个主视图。周视图长按任务拖到其他日期或时间，时间按 15 分钟落点；月视图长按任务条目拖到其他日期。
- 保留原任务的全天属性、跨日长度、完成状态及重复规则；月视图改日期保留具体时刻。多日任务拖动会整体移动。
- 全天区默认仅展示每一天的一个任务与“+N”，可展开/收起；展开内容过多时在限定高度内滚动，为时间区保留空间。
- 拖到周视图边缘可滚动日期/时间区域，月视图可在上下边缘滚动。拖到任务覆盖的位置也能识别落点。
- 改期后提示新日期并提供撤销；保存前检查日期是否被其他操作改动，撤销也不会覆盖后续日期变化。详细编辑继续放在任务详情中。
