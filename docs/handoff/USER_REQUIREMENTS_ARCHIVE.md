无论是金融后台、项目管理平台，还是SaaS系统，这类设计都在追求同一个目标： 信息密度高，但浏览依然轻松。

📌 ① B端首页，不是在堆模块，而是在做信息层级 很多新手做后台首页，喜欢把所有数据都放出来，结果就是用户不知道先看哪里。

✅ 第二层：趋势分析（折线图、柱状图）
✅ 第三层：明细列表（表格、任务、消息）
✅ 第四层：辅助信息（快捷操作、通知、个人中心）

▫统一间距（8 / 16 / 24 设计体系）
▫圆角保持一致 ▫阴影尽量轻，不要抢戏
▫用留白代替复杂分割线
尤其是B端后台，留白越舒服，信息越容易阅读。

这类 Dashboard 我一般不会超过 3 个主色。

🟣 深紫色：导航、重点按钮
🟢 青绿色：增长、核心数据

剩下大量内容都交给中性色。
