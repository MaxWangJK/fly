==================================================
PART A — 修复“今天”任务筛选逻辑
==================================================

当前 Bug：

Task 设置：

startDate = today

或者：

dueDate = today

有时不会出现在：

Tasks → Today

这是错误行为。

“今天”不是只判断某一个字段是否正好等于今天。

必须使用：

# 时间区间是否与今天发生交集

作为统一规则。

==================================================
一、Today 的业务定义
==================================================

假设：

today = 2026-09-07

startOfToday：

2026-09-07 00:00:00

endOfToday：

2026-09-07 23:59:59.999...

如果 Task 的有效时间范围：

和今天有任何重叠，

则：

Task 应该出现在 Today。

前提：

Task 未完成
Task 未删除。

==================================================
二、必须出现的情况
==================================================

Case 1：

startDate = Sep 7
dueDate = null

→ Today 显示

--------------------------------------------------

Case 2：

startDate = null
dueDate = Sep 7

→ Today 显示

--------------------------------------------------

Case 3：

startDate = Sep 7
dueDate = Sep 7

→ Today 显示

--------------------------------------------------

Case 4：

startDate = Sep 6
dueDate = Sep 8

→ Today 显示

因为：

Sep 7 位于任务有效时间范围中。

--------------------------------------------------

Case 5：

startDate = Sep 1
dueDate = Sep 30

→ Sep 7 Today 显示。

--------------------------------------------------

Case 6：

startDate = Sep 8
dueDate = Sep 10

→ Sep 7 Today 不显示。

--------------------------------------------------

Case 7：

startDate = Sep 1
dueDate = Sep 6

→ Sep 7 Today 不显示。

如果现有产品有“Overdue”独立逻辑：

仍然由 Overdue 处理。

==================================================
三、只有 Start Date
==================================================

如果：

startDate != null
dueDate == null

推荐语义：

Task 从：

startDate

开始有效。

但是不能因此让它未来每天永久进入 Today。

为了符合当前 Todo 习惯：

如果只有 Start Date：

仅：

calendarDate(startDate) == today

时进入 Today。

不要把：

Sep 1 startDate
没有 dueDate

在 Sep 7 仍然显示 Today。

==================================================
四、只有 Due Date
==================================================

如果：

startDate == null
dueDate != null

则：

dueDate == today

→ Today

如果：

dueDate < today

由：

Overdue

处理。

==================================================
五、同时存在 Start + Due
==================================================

这是时间区间任务。

条件：

startDate <= endOfToday
AND
dueDate >= startOfToday

则：

Today 显示。

也就是说：

Today ∈ [startDate, dueDate]

==================================================
六、没有 Start / Due
==================================================

如果：

startDate == null
dueDate == null

不因为日期进入 Today。

除非：

Task 本身被用户明确创建在 Today List，
并且现有 Domain 有 today bucket / scheduledToday 等机制。

保持现有无日期 Task 规则。

不要擅自把所有无日期任务放进 Today。

==================================================
七、Completed
==================================================

如果：

completedAt != null
或者
isCompleted = true

Today：

# 不显示

无论：

startDate
dueDate

是否包含今天。

这是强制要求。

==================================================
八、Deleted
==================================================

deletedAt != null

Today：

不显示。

==================================================
九、统一 Task Today Query
==================================================

不要：

Task List 一套逻辑

Calendar 一套逻辑

Dashboard Today Tasks 又一套逻辑。

建立统一 Repository / Query：

watchTasksForToday(date)

或者：

TaskDateQueryService

所有：

Tasks → Today
Dashboard → Today Tasks

都复用。

==================================================
十、推荐 Query 逻辑
==================================================

概念伪代码：

if completed or deleted:
    false

if start != null && due != null:
    return start <= endOfDay(today)
        && due >= startOfDay(today)

if start != null && due == null:
    return sameCalendarDay(start, today)

if start == null && due != null:
    return sameCalendarDay(due, today)

if start == null && due == null:
    return existingTodayBucketLogicIfAny()

十一、DateTime 与 Date-only
==================================================

检查当前 Task：

dueDate

究竟是：
