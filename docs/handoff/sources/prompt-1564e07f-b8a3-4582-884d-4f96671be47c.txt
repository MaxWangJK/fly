==================================================

==================================================

Customer Follow-up Extension 当前有：

记录本次跟进

和：

下一步

# 两个输入框中任意一个不为空，都可以保存。

重新计算一个10柜方案

一次保存两部分内容。

==================================================
二、Enter 行为
==================================================

如果当前 focus 在：

记录本次跟进

按：

Enter

如果：

followUpContent.trim().isNotEmpty
OR
nextAction.trim().isNotEmpty

则：

保存。

同样：

focus 在：

下一步

按 Enter：

也执行同一个保存逻辑。

如果两个都为空：

不保存。

==================================================
四、保存后的行为
==================================================

保存成功后：

1. 创建 CustomerFollowUp
2. followedUpAt = now
3. 如果 content 非空：
   保存 content
4. 如果 nextAction 非空：
   保存 nextAction
5. 更新 Customer.lastFollowUpAt = now
6. Customer Detail 顶部 Next Action 立即刷新
7. 新 FollowUp Block 出现在历史最顶部
8. 两个输入框清空
9. Focus 保持在主要 Follow-up 输入区域

不要弹：

“保存成功”

Snackbar。

视觉更新本身就是反馈。
