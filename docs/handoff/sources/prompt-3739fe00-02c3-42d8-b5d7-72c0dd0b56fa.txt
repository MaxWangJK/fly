# Fly Polish V6
# 项目目录：E:\workSpace\fly

当前 Fly 已经完成并且整体功能/UI状态需要保留：

- 客户管理
- 订单管理
- 任务
- 日历
- 四象限
- 客户跟进/备注
- 订单财务
- 订单详情/工厂产品
- 文件管理
- 标签体系
- 优先级体系
- Windows Installer
- 初始演示数据
- 当前 Design System / Color System

本轮禁止：

- 重做现有架构
- 大规模重构数据库
- 改变用户已经习惯的整体布局
- 破坏 Task / Calendar / Matrix 现有视觉
- 新增复杂 ERP 模块

本轮目标：

1. 优化订单财务信息结构
2. 支持单笔金额 USD/RMB
3. 支持订单级 USD→RMB 汇率
4. 最终利润统一用 RMB
5. 简化订单优先级为重要/紧急/一般
6. 优化客户优先级展示
7. 调整客户来源位置
8. 修复订单详情工厂/产品/成本编辑体验
9. 修复 Fly 启动窗口位置
10. 新增 Excel 导出
11. 新增多套主题配色
12. Task 改为直接输入回车新增
