# 十六、Basic Grid Packing

第一阶段首先实现：

# Axis-aligned Grid Packing

即：

对于同一种规则长方体货物：

尝试所有允许旋转方向。

货物尺寸：

```text
L
W
H
```

所有可能 orientations：

```text
L W H
L H W
W L H
W H L
H L W
H W L
```

去掉重复组合。

---

# 十七、Orientation Evaluation

对于每一种 orientation：

计算：

```text
nx = floor(containerLength / cargoLength)
ny = floor(containerWidth / cargoWidth)
nz = floor(containerHeight / cargoHeight)
```

Capacity：

```text
nx × ny × nz
```

然后：

根据：

```text
数量
重量
空间利用率
```

评估。
