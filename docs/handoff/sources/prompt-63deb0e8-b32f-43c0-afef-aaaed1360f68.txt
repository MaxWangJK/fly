# Fly CRM / Orders Polish V2 — 标签、客户详情、订单详情与扩展面板微调

当前项目：

```text
E:\workSpace\fly
```

当前已经完成：

```text
任务
日历
四象限
客户管理
订单管理
客户备注扩展面板
客户跟进记录扩展面板
订单财务
订单工厂/产品
订单文件
```

本轮不新增大模块。

目标：

# 进一步减少视觉噪音
# 减少标题和表单感
# 提高外贸员每天高频使用效率
# 让客户和订单详情更紧凑
# 让复杂信息通过右侧 Extension Panel 展开

不要破坏现有数据层、Riverpod、Repository、Drift、SQLite。

# 八十八、最终产品判断

完成后检查：

# 客户详情是否更短？

# 标签是否不会无限占一行？

# 无用标签是否会自动消失？

# 打开订单第一眼是否看到客户和状态，而不是一堆财务数字？
