PART N — 用户经验优先 Override
==================================================

重要业务要求：

用户经常知道：

“一节实际可以装多少”

但纯尺寸算法未必理解：

包装挤压
人工错位排列
实际装柜经验
包装形变
预留方式

因此：

如果：

defaultSectionQuantity / 用户输入数量

大于算法理论可装数量，

不要直接拒绝。

显示：

⚠ 当前数量超过系统根据尺寸计算的理论容量。

系统计算：
280

用户设置：
286

[修改数量]
[仍按286继续]

--------------------------------------------------

如果用户选择：

仍按286继续

则：

Plan Item：

manualQuantityOverride = true

quantity = 286

后续：

# 不再次阻止用户
# 不再次自动修改这个数量

但是 UI 需要有一个轻量警告：

“用户覆盖理论容量”

避免软件假装数学上完全成立。

--------------------------------------------------

不要每次重新计算又把286改回280。

用户确认后：

尊重用户业务经验。
