PART A — Task Today 与 Calendar 统一时间逻辑
==================================================

假设今天：

2026-09-08

Task：

startDate = 2026-09-07
dueDate   = 2026-09-10

则：

这个 Task 在：

Sep 7
Sep 8
Sep 9
Sep 10

四天都属于有效任务。

因此：

Tasks → Today

在 Sep8：

必须出现。

Calendar：

Sep7 / Sep8 / Sep9 / Sep10

都必须显示。

数据库中：

仍然只有一条 Task。

绝不能为了 Calendar 创建4条 Task。

--------------------------------------------------
一、统一 Task Date Range
--------------------------------------------------

建立：

TaskDateRangeService

或者等价纯 Domain Utility。

如果：

startDate != null
dueDate != null

有效区间：

[startDate, dueDate]

包含首尾。

条件：

date >= startDate
AND
date <= dueDate

--------------------------------------------------
二、Today Query
--------------------------------------------------

Task 未完成
AND
未删除

并且：

如果 start + due 都存在：

today ∈ [start, due]

则进入 Today。

--------------------------------------------------
三、只有 Start
--------------------------------------------------

如果：

startDate != null
dueDate == null

只在：

startDate 当天

进入 Today。

不要以后每天一直出现。

--------------------------------------------------
四、只有 Due
--------------------------------------------------

如果：

startDate == null
dueDate != null

dueDate == today：

Today。

dueDate < today：

Overdue。

--------------------------------------------------
五、Completed
--------------------------------------------------

completed == true

不进入：

Today
Overdue

Calendar 是否保留 Completed：

继续使用当前已有产品逻辑。

不要本轮改。
