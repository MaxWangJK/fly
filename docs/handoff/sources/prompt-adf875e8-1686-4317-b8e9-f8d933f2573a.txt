==================================================
一、产品定位
==================================================

这个区域不是：

励志名言播放器。

不要默认展示：

“越努力越幸运”
“坚持就是胜利”

这种没有业务价值的鸡汤。

它应该是：

# 外贸业务员每天打开 Fly 时看到的个人方向板。

帮助用户回答：

1. 我长期到底在追求什么？
2. 这周最重要的事情是什么？
3. 今天最不能忽略的事情是什么？

==================================================
二、Focus Board 三个层级
==================================================

默认包含三个内容：

1. 人生主线 / Main Mission

2. 本周重点 / Weekly Focus

3. 今日提醒 / Today Focus

例如：

人生主线

不遗余力地开发客户，
建立属于自己的稳定客户池。


本周重点

重点开发菲律宾建材经销商，
完成100个有效客户触达。


今日提醒

坚持开发15个新客户，
先开发，再处理低价值杂事。

推荐 Daily Focus 按日期保存，
