# Fly V12 — 外贸资料库 / Knowledge Hub / SOP System
# 项目目录：E:\workSpace\fly

本阶段目标：

将当前 Fly 的“笔记”一级模块升级为：

# 资料库 / Knowledge Hub

但不要删除原有用户笔记能力。

新的产品结构：

资料库
├── Fly 外贸资料
└── 我的笔记

其中：

Fly 外贸资料
= 开发者发布的只读知识内容

我的笔记
= 当前用户自己的私人 Notes

========================================================
0. 核心产品定位
========================================================

资料库不是：

文章列表
博客
简单 Markdown 阅读器

而应该逐渐成为：

# 外贸业务员完整 SOP + 话术 + 方法 + 模板 + 学习资料中心。

它同时承担两个作用：

1. 帮助现有用户学习和执行外贸工作
2. 作为 Fly Free 的核心免费内容，用于短视频平台获客和用户留存

用户可以免费阅读部分/全部官方资料。

官方资料由开发者编辑和发布。

普通用户：

不能修改官方资料。

用户自己的内容：

继续在“我的笔记”中编辑。

28. 内容复制策略
========================================================

用户要求官方内容尽量不可复制。

建立：

copyPolicy：

none
snippet
full

--------------------------------------------------------

none：

禁止：

text selection
Ctrl+C
Context Menu Copy

HTML：

user-select: none

Intercept：

copy event

--------------------------------------------------------

snippet：

只允许开发者指定：

:::copyable

区域复制。

适合：

开发者自己原创的话术。

--------------------------------------------------------

full：

整篇允许复制。
