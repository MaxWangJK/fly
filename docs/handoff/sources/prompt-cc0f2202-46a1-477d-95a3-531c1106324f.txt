--------------------------------------------------

没有入口填写“下一步”。

因此 Customer Detail 顶部显示的：

“下一步：xxxx”

仍然可能是上一次 Follow-up 的 nextAction。

这是错误的。

id
customerId
content
channel
followedUpAt
nextAction
nextFollowUpDate
createdAt
updatedAt

--------------------------------------------------
三、Customer Detail 顶部“下一步”读取规则
--------------------------------------------------

不要继续保存一份独立的 stale nextAction UI state。

Customer Detail 顶部：

下一步

应该从 Repository 查询：

latest CustomerFollowUp
WHERE nextAction IS NOT NULL
AND trim(nextAction) != ''
ORDER BY followedUpAt DESC
LIMIT 1

如果没有：

不显示旧值。

可以显示：

“暂未设置下一步”

或隐藏该区域。
