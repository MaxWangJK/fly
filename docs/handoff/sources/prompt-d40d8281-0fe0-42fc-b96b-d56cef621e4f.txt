# Fly CRM / Order 微调 V1 — 客户详情、优先级、重复跟进、备注与跟进记录重构

当前项目：

```text
E:\workSpace\fly
```

当前 Fly 已经完成：

```text
客户管理
订单管理
任务
日历
四象限
```

本轮：

# 不新增大模块。

只做 CRM / Order UI 与交互微调。

不要破坏已经完成的数据层、Repository、Drift、SQLite 和现有业务逻辑。

目标：

```text
减少点击
减少视觉占用
提高跟进效率
让客户详情更紧凑
让备注和跟进历史更适合长期积累
```

---

# 一、客户详情新增“新建订单”

这是强制需求。

Customer Detail 顶部或订单区域增加：

```text
+ 新建订单
```

点击以后：

# 不要跳到订单列表再让用户重新选择客户。

直接创建：

```text
Order.customerId = 当前客户.id
```

然后：

自动进入：

```text
Order Detail
```

让用户继续填写订单信息。

# 十六、三天规则

如果：

```text
recurrence = every3Days
```

计算基准：

优先：

```text
nextFollowUpDate
```

如果：

```text
nextFollowUpDate != null
```

则：

```text
next occurrence = nextFollowUpDate + 3 days
```

---

# 十七、没有 Next Follow-up Date

如果：

```text
recurrence = every3Days
```

但是：

```text
nextFollowUpDate = null
```

则：

```text
baseDate = today
```

然后：

```text
nextFollowUpDate = today + 3 days
```

---

# 十八、每周


---

# 十九、两周
