# Fly 书籍阅读：2.0.3 build 39

本次增加任务“我的聚焦”中的“我的座右铭”，位于人生主线上方，沿用 800 字、多行编辑、自动保存和历史。使用既有聚焦表，不重建数据，数据库仍为 schema 19。

桌面资料库改为书籍阅读。左侧只保留书籍及章节两级目录，右侧直接阅读；没有第三层文章列表、章节子目录、搜索、标签筛选、笔记编辑或另存笔记按钮。原笔记、块内容、标签、草稿、附件、收藏与旧官方资料没有删除。手机五个主入口保持不变，手机设置也隐藏资料库分类。

页面右上角提供 `.fly` 导入和阅读历史。书架显示总进度和继续阅读；各章保存最后浏览比例、最大浏览比例及最近阅读时间。全书进度是当前章节浏览比例的平均值，不是理解程度或实际投入时间。历史显示每章最近阅读，旧版更新保留相同章节 ID 的进度；手机/电脑的进度暂不云同步，随本机数据库备份。

HTML 展示支持自定义背景、排版、表格和配套图片，普通用户只读。用户可以切换章节、从历史继续、标记本章已读。WebView2 是 Windows 的 HTML 显示依赖；缺失时提示具体原因与重试，不能把阅读器未加载当作成功显示。

## `.fly` 保护格式

本格式不是改后缀 ZIP。`FLYBOOK1` 文件头包含版本标识、压缩/解压尺寸和随机 nonce；正文先压缩再 AES-256-GCM 加密，最后对完整文件头、密文和认证标签进行 Ed25519 签名。读取先校验签名与尺寸，再解密，解压有实际输出字节上限。书籍身份、版本、章节、CSS、HTML 和图片均在密文中。

导入只持久保存签名加密的 `.fly` 文件到 `FlyData/knowledge/books/`，不展开 HTML、CSS 或图片目录。图片解密后以内嵌 data URI 在 HTML 内显示；书籍没有图片单独查看、下载、分享或素材导出入口。JS、事件属性、远程 CSS/图片、文件 URL、表单和嵌入框架不允许进入书包。阅读器只执行应用自己提供的滚动/章节桥接脚本，并用 CSP 限制资源；Windows 禁用常规开发工具及上下文菜单。

坏包、错误签名/密钥、超限结构、脚本内容和同书较旧版本被拒绝；校验完成前不替换已导入书籍。读者不需要输入作者密钥。编译时配置的内容密钥会进入执行程序，因此不是不可破解的 DRM，不能阻止有能力的逆向、内存抓取、截图或 OCR。应用自身不把解密素材保存成文件；操作系统与 WebView 的内部实现不作为绝对保密保证。

## 作者工作流与迁移

编辑 `book_sources/foreign_trade` 的 HTML/CSS/图片，保持书籍和章节 ID，增加整数版本后运行 `tool/build_fly_book.dart`。导出工具回读验证签名和解密；原有资料签发 seed 不覆盖。阅读器使用 Git 忽略目录下的 `book_build_defines.json` 编译，源码没有硬编码新内容密钥。

完整项目迁移时，作者稿和两个内部密钥文件需要安全带走。客户只收到安装包和 `.fly`；不要把作者工程、调试符号或私钥当作客户安装包。备份机制会带走加密书籍目录和数据库中的进度。

macOS / iOS 代码沿用已有 HTML 平台适配，当前 Windows 环境没有进行 Apple 构建或真机验收。Android 的资料库入口仍隐藏；座右铭适用于任务模块。
