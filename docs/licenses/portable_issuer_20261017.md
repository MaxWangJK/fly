# Fly 免安装授权工具

2026-10-17，内部工具 1.0.0。适用于 Windows 10/11，当前已在 Windows .NET Framework 4.8 环境验证。Fly 主程序版本仍为 2.0.4+40；本次制作独立发码工具。

## 打开与使用

工具在 `license_tools/private/portable/Fly-License-Issuer.exe`。双击运行，无需安装工具、Python 或额外 DLL；移动到另一台已具备 .NET Framework 4.8 的 Windows 电脑时，运行只需要这个 EXE。

1. 粘贴 Fly 显示的完整 64 位机器码，支持自动去空白和转换大写。
2. 选择“按天授权”，填写 1～36500 的整数天数，或选择“永久授权”。默认 30 天。
3. 点击“生成授权码”，检查期限，再点“复制授权码”。将完整结果交给对应机器的用户粘贴激活。

**天数从生成时开始计算，而不是第一次激活时。** 生成后修改机器码、期限模式或天数，会清空旧结果；再次生成后才能复制。每次签发使用新的随机 nonce；结果绑定一台机器，不能用于另一台。

“永久”采用现有协议的 `9999-12-31T23:59:59Z`，与官网既有永久授权格式兼容；无需改客户端验证算法。工具会先核对原签发身份与 Fly 公钥，并对刚生成的签名进行自检。

## 如何验证实际激活

当前 build 40 功能测试包（包括后续正式安卓签名备案包）沿用 `ENABLE_LOCAL_LICENSE=false`，因此没有启用离线试用锁定和激活流程。工具生成有效授权码不代表测试包会自动出现激活入口。

需要实际验证 Windows 离线激活时，使用启用 `ENABLE_LOCAL_LICENSE=true` 且包含原 `LOCAL_LICENSE_PUBLIC_KEY` 的 Fly 构建，在隔离 Windows 用户或虚拟机测试。原有 72 小时试用、到期锁定、激活保存由客户端负责，不能通过这个工具去改真实电脑时间、清理注册表或重置试用。Mac/手机的商业授权和设备身份仍有独立待验收事项。

## 内部保管与迁移

**此 EXE 具有原签名的发码权限，只给所有者和可信发码人员保管，不能发给客户。** 只将生成的授权码交给对应用户。单文件中包含签发身份，不承诺无法提取；压缩和混淆不能保护被公开的发码工具。

工具及构建目录在 Git 忽略的 `license_tools/private/` 中，不进入客户安装器和公开下载。目录已设置本机访问权限；迁移后按新电脑账户重新保护。原 `issuer.pem` 和其他签发密钥仍应独立安全备份，不能以仅保留 EXE 代替原始密钥备份，也不能因文件缺失重新生成替代身份。

迁移到 Mac 可安全保管此工具及原密钥，但 EXE 只在 Windows 运行；Mac 继续使用原 Python 签发器或后续原生工具，不能把安卓、书籍或 iOS 签名拿来替换授权签名。
