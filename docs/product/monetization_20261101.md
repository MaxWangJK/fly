# Fly 收费建议：为持续价值付费

2026-11-01。以下为建议，不是用户确认的新开发清单，也不是当前软件的收费政策。本轮仅实现两种复盘入口与进阶开放体验，没有实施配额、会员、支付或订阅。

## 建议的边界

不建议以本地文件夹、标签、客户的微小数量限制作为主要变现方式。配额是成熟的商业手段，但当用户感觉其目的只是阻止正常整理资料，付费更像解除阻碍。服务端存储、保留时长、团队席位等则有真实成本或协作价值，使用额度更容易解释。

| 能力 | 建议 |
| --- | --- |
| 基础任务、客户、订单、文件整理、原有复盘与历史 | 保持完整可用，形成可靠的日常工作闭环 |
| 标签与本地文件夹 | 不逐项售卖，不故意制造很低的上限；异常使用保护和商业分层分开设计 |
| 局域网同步 | 保留为产品基础能力，尤其不在用户已经依赖电脑手机配合后突然关闭 |
| 自建同步服务器 | 建议继续开放；用户自行承担服务器维护和网络成本 |
| 官方托管云服务 | 可选订阅；价值来自跨网络可用性、维护、备份与恢复服务，而非“允许点击同步”。备份和恢复承诺须先实现、验收再售卖。当前云同步仍只有结构化数据，不含实体文件 |
| 航向复盘与方法包 | 可作为专业权益或独立买断；单纯增加问题数量难以支撑长期订阅，行动回看、跨周总结、持续更新的行业方法才是价值 |
| 外贸业务分析 | 后续优先验证：跟进节奏、报价转化、失单原因、交付风险等。把洞察落实为任务，比限制客户数量更有说服力。这些分析尚未在本轮实现 |
| 团队协作 | 未来按席位收费，提供客户交接、角色权限、共享流程和审计；须先开发，不把当前个人版包装成团队版 |
| 专业书籍与内容 | 可独立售卖内容许可或方法包，保持软件和内容权益清楚 |

## 可测试的起步价格

以下为产品假设，未证明支付意愿，不是竞品价格换算，也不写入当前页面。

- **仅航向复盘模块**：可先测试一次性 49–79 元。当前五步引导、小实验回看与七日收束适合轻量买断；后续大版本升级规则需提前说明。
- **完整个人专业版**：等业务分析与持续维护的专业能力形成后，再测试 129–199 元/年。不要只靠更多问答或更多颜色支撑年费。
- **官方云服务**：按实际带宽、数据库、备份、支持成本测算后报价，和本地专业版分别说明，支持可选组合。不建议承诺包含永久云成本的终身买断。
- 初期保持一套免费方案、一套清晰的专业方案；云服务可选。不要同时销售许多零碎开关。团队版待真实团队场景验证后再定价。

先让目标用户完整使用两个工作周，观察他们是否真的回看实验、在下一周继续使用，以及愿意为哪种成果付费。不要只询问是否喜欢界面，也不必为研究采集客户或复盘正文。退款、续费和失效后的权益应在支付开发时完整设计，不用模糊试用到期或付款提示催促决策。

## 信任规则

当前免费体验不计时、不自动扣费、不绑定支付方式。将来收费前清晰说明生效时间、权益和迁移安排；既有基础功能不因这轮试验被悄悄收回。即使以后专业订阅失效，也应继续允许阅读、备份和导出用户已经写下的记录，不把个人内容当成续费筹码。

当前的接入码只是临时设备身份，不是会员凭证；原本的离线授权工具也不能代替未来用户级权益系统。后续收费应在独立的权益层接入，统一跨设备授权，不修改复盘答案来表示是否付费。

## 公开参照

查阅日期 2026-11-01，产品和地区价格可能继续变化：

- [Todoist 官方价格](https://www.todoist.com/pricing)：免费版包含基础任务与有限项目/筛选；专业版增加日历、完整报告历史等，团队版增加共享空间、权限等。说明容量分层与功能价值可以同时存在，但 Fly 不必照搬其项目数。
- [Day One 官方方案](https://dayoneapp.com/plans/)：免费版提供不限文字日记、日记本以及标签/搜索；更高方案增加多设备、媒体、集成和深入反思能力，数据导出在各层保留。其持续服务和深度反思分层可作为参考。

上述案例证明的是不同的分层选择都存在，并不能证明 Fly 用户一定接受某个价格。Fly 的判断应来自外贸用户的工作收益和实际使用反馈。
