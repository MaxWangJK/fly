# 航向复盘：从观察到行动

2026-11-01。基于当前 `codex/fly-2-sync` 工作区，源码仍为 2.0.7+43，沿用 schema 20。本轮未提交、推送或打包。此需求新增进阶复盘，不替换基础复盘及其历史卡片。

## 两个入口，各自保留

第一次打开任务中的复盘，展示两个方案卡：

| 方案 | 当前行为 |
| --- | --- |
| 基础复盘 | 默认、免费；保留既有 q1–q11、编辑收起、历史卡片、日期切换、统计及同步刷新 |
| 航向复盘 | 规划为进阶付费方案；当前可浏览示例，也可免费体验并保存自己的记录 |

选择后记住本设备的方案，下次直接进入；通过“复盘方案”随时切换。老用户尚未选择时也会看到这两个卡片，原记录不删除、不转成新格式。浏览示例不会选定方案，不写入复盘、不创建任务；明确开始体验后才进入个人记录。

目前没有价格、购买、订阅状态、支付跳转或虚构试用倒计时。界面明确告知“当前免费体验，不产生费用”。正式计费和支付方式留待后续另行开发。

## 原创方法与引导

参考用户提供图片中“多角度观察、事实与解释分开、小行动、后续回看”的理念，重新设计成人工作与生活场景的流程。未复制图片、版式、引导文案、作者标识或儿童学习量表。

**观察变化 → 看清偏差 → 找到可控的一环 → 小实验 → 验证结果。**

| 每日提示 | 要解决的问题 |
| --- | --- |
| 留下一个真实进展 | 记录具体变化，而非用忙碌程度评价一天 |
| 看清一次偏差 | 区分原先期待和实际发生，先留事实 |
| 找到可以改变的一环 | 分清已知原因与猜测，关注可控的行动、方法、沟通和精力 |
| 安排一个小实验 | 为下一天选择一个具体、足够小的动作 |
| 约定一个回看信号 | 明确何时回看、观察什么；没有预期结果也保留证据 |

可选择工作、生活、成长、关系与陪伴作为当天的观察角度；精力只分需要恢复、平稳、充足，不计算人格、健康或能力评分。不要求用户具备育儿身份，也不要求填满每道题。

下一次写复盘时，展示最近一次有小实验的历史记录，可标记有帮助、调整后再试或还没尝试，并补充观察。反馈保存在当前日期，并记录其对应的原实验日期；不改写昨天的答案。

“收好今天”后可将个人记录作为航向卡阅读，再点击继续编辑。进阶历史与基础历史分别展示；进阶历史先展示 20 份，可继续展开。

## 与任务连接

用户主动点击“小实验加入次日任务”，保存当前输入后，将动作加入收集箱，日期为**当前所选复盘日期的次日**。标题来自第一行，完整行动与回看信号在任务说明中；没有自动添加提醒或后台批量创建任务。

同一天的动作使用稳定 ID，任务和复盘引用在一个事务中保存。同设备重复点击，或不同设备离线创建同一天的实验任务，不会生成两种随机 ID。已经创建的任务不会随复盘修改而被悄悄改写或从回收站恢复；用户在任务模块继续管理它。

## 七日校准

范围是所选日期及之前六天，不是固定自然周。展示真实的观察天数、小实验数与结果回看次数，列出七天的记录，再填写三个收束问题：

1. 哪个做法值得继续？
2. 什么应该停止或调整？
3. 下一程只聚焦哪一件事？

校准笔记保存在所选日期，可以修改。没有填写的日子允许留白，不制造补签压力。当前提供事实回看和人工归纳；没有实现自动生成结论、趋势预测、AI 分析或后台评分。

## 保存、兼容与同步

- 基础答案仍使用 q1–q11；航向答案使用 `flight.v1.*`。两个仓库按自己的字段读写，并在同一日的同步 JSON 中保留另一套答案。不是整行替换，更不会把旧答案映射到新问题。
- 原数据库表和主键不变，不增加数据库迁移，不生成新表代码。已有备份会包含新字段。
- 历史、已记录日期和可见卡片按方案筛选，关闭状态、任务引用等元数据不会单独生成空历史卡。
- 沿用上一轮的按问题字段时钟合并；基础与进阶的不同答案可跨端并存。该选择偏好只存本机，不占用业务云同步记录。
- 输入自动保存；切日期、切方案前等待保存。失败保留当前输入，允许重试。保存状态指本机落库，不假称已经上传。
- 进阶记录与既有复盘同样通过本地/云端结构化同步传输；没有新增图片、文件传输或支付权限判断。
