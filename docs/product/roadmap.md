# Roadmap

## V1 hardening

- Keyboard shortcuts and focus traversal
- Accessible labels and contrast audit
- Full task-list management UI
- Migration and backup/restore tests
- Recurrence engine and native reminder adapter
- Installer packaging and signed releases

## Later cross-platform work

- Validate macOS on macOS hardware
- Configure Android toolchain and validate responsive mobile flows
- Validate iOS with macOS and Xcode
- Add platform adapters only where operating systems require them

## Future sync discovery

Define conflict semantics, tombstone retention, encryption, account model, and a replayable operation protocol before selecting a server. V1 metadata keeps this possible but does not claim it exists.
