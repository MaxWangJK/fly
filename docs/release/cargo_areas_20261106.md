# Windows 2.0.13+49：按区域装货与剖面右键

2026-11-06。截图对应问题是第二组经通用入口落在柜底，与第一组重叠，3D中被遮挡；不是3D丢失了货物数据。

## 最终交互

- 空分节保留首次选货/拖放。已有货物后隐藏通用入口并在控制器拒绝无区域追加；后续必须选择真实空闲区域。
- 剖面和卡片统一A区、B区等名称，卡片显示长×宽×高。点剖面的区域可选货物，也可向区域卡拖放。已过时或尺寸不适配的区域不能追加；500mm余隙规则保持。
- 区域追加同时支持合适尺寸的托盘/木箱，按区域坐标摆放，避免移除通用入口后损失这项能力；首次托盘仍使用原自动装柜。
- 剖面货物右键：绕X/Y/Z旋转90°、移除货物。只操作命中组，与3D共享数据、支持撤销/重做；旋转冲突或越界会拒绝并提示。旧重叠方案保留原位置，不自动搬动或删除。
- 清空/0件草稿不占区域；移除所有已装组后可再次首次添加。区域字母只用于当前展示，原空间ID、方案及数据库兼容；SQLite20及后台0004不改。
