# Windows2.0.12+48：货物数量实时计算与可见移除按钮

2026-11-06。用户反馈：新增第二组PVC ceiling后清空数字，3D仍保留原货物；人工界面缺少直观的移除入口。

## 原因与修复

- 原人工编辑将空值/0当作无效输入，只显示红字，保留上次有效几何；自动输入为空时还会回退推荐值。现在清空或填0立即按0件计算，输入行保留便于继续编辑，3D/剖面/重量/已装和可用空间同步更新。
- 0件草稿不占空间、不参加碰撞和图例，补齐正整数后恢复当前组；不重新排布其他货物。保存重开仍为未装载状态。保留最后有效的单位尺寸供重新填写，不创建零尺寸几何对象。
- 每组每排数量/层数下方增加带文字的“移除货物”按钮，自动模式、人工模式和柜外货物均可操作。人工组移除可用撤销恢复。只影响当前组的方案位置，货物库保留；同名货物独立。
- 数量/排数修改、复制、移除、撤销和重做同步来源数量；纯位置移动继续保留已确认的未装数量。已移除组在保存和重新自动装柜后不再恢复。手动模式标识保存在原有layoutV3 JSON中，旧方案缺字段时兼容默认及几何识别。
- SQLite结构20、后台API/迁移0004不改。保留之前的剩余空间修复。原网站和独立书稿工作区修改不纳入本次提交。
