# 2026-11-06 装柜剩余空间修复（Windows2.0.11+47）

用户反馈：PVC ceiling设置每排8件、10层后，只显示货物剖面，没有上方和侧方剩余空间。

## 原因核对

历史需求TOOL-05/06和V5/V6空间拆分仍在。最早可追溯的1.0提交19b711f（2026-09-29）已包含：人工模式通过else跳过_spaces；自动模式也只在有托盘/木箱或空间分配时显示空间。普通PVC无托盘、手动改数量或拖动后都可能看不到。这段装柜代码在随后2.0同步提交中没有被删除。

原spacesFor还会根据原输入重新模拟自动排布，并非当前场景。因此只去掉隐藏条件，会产生与实际位置不一致的空间，仍不能正确修复。

## 修复行为

- 人工模式和普通无托盘货物，根据当前场景包围盒拆分互不重叠的空闲长方体，沿用整数mm、可堆叠、500mm边界和稳定几何标识。柜外货物不占用空间，跨节相交货物参与扣除；不对已有货物重新自动排布。
- 可拖动剖面与卡片使用同一组空间，剖面显示边界、编号和宽高。合格空间可继续选货，新货物放到目标空间原点，原货物保持位置；失效或超尺寸选择不新增任何货物。自动托盘的旧空间关联、递归分配及悬出规则继续保留。
- 8×10 PVC的实际尺寸2900×2000×1000mm：上方2900×2000×1690mm显示装货卡，侧方200×2690mm仅显示余隙文字及边界；原规则是宽或高小于500mm不推荐装货，等于500mm仍显示。
- 6×10时PVC宽1500mm，侧方700mm，上方与侧方各一张空间卡。修改数量、拖动、撤销/重做后实时更新。保存后按几何对比识别没有冲突警告的人工位置，重开后保持空间提示及人工模式。
- 箱型尺寸缩短后，旧方案仍可打开；保留原货物并提示原分节超出边界，剩余空间截取在当前箱体内，不在箱外推荐装货。
- 不改数据库结构、后台API或用户业务数据。Windows修复版本2.0.11+47；最新Android包仍是2.0.10+46，手机当前隐藏工具入口。本次原有官网和独立书稿目录的修改不纳入本次提交。
