# 客户与订单列表字段名称

日期：2026-10-31。源码版本字段仍为 `2.0.6+42`、数据库 schema 19；未重新打包，现有 build 42 安装包不包含文件移动和本次列表改动。

## 已实现

- 桌面客户列表固定显示客户名称、国家、客户状态、最近跟进；末列标注优先级，并提示该区域还显示下一步行动。
- 桌面订单列表固定显示订单号、客户名称、订单状态、订单日期。
- 表头与记录共用列宽和间距；恢复按钮、不同长度的下一步行动不再推移其他列。空列表也显示字段标题，滚动时标题保留。
- 手机/窄屏保留卡片布局，直接为上述值标明字段名称；客户原有公司、电话和邮箱仍显示在资料摘要中，不改点击详情和右下角新增。
- 客户时间列使用既有最近跟进时间，未跟进显示原提示；没有改成创建日期。订单日期继续使用订单日期，空值按原逻辑回退创建日期。
- 新增表头支持中文/英文。标签筛选的测量与高度适配字体缩放，修复英文 1.3 倍字体下的溢出。用户自己填写的名称、状态及下一步类型数据不因界面语言而改写。

## 验证

5 项新增界面场景通过：桌面 1400×900 中文、900×800 英文与 1.3 倍字体；手机 390×844、320×720 大字和 844×390 横屏。检查列对齐、手机值标签、空订单列表与已删除订单恢复列。另有 7 项已有客户/订单交互、4 项跟进/财务界面和 1 项两行标签筛选回归通过，共 17 项针对性检查。静态分析无问题。

已检查渲染截图，截图可通过 `FLY_CRM_COLUMNS_CAPTURE=true` 重现于忽略目录 `build/crm-columns-*.png`。未使用真实业务数据；未重跑完整客户端测试或制作新安装包，未进行 Android/iOS 真机验收。完整客户端 352 项仍是 2026-10-17 的历史结果。
