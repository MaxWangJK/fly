# 资料库默认隐藏与桌面文件操作

2026-11-12源码续补，基于`40eeba9`。后续按用户要求，功能源码保存为`980f23ea3774b2a4c1e64b816270e7e52599e387`并打包Windows/Android2.0.23+59；原build58不包含这些变化。[交付记录](fly_2_0_23_build59.md)。

## 使用行为

- 资料库默认隐藏。旧导航设置缺少此选项时也默认隐藏；桌面可在“设置 → 导航 → 显示资料库”重新开启，并记住选择。隐藏后不显示一级入口和资料库设置分类，直接进入隐藏路由会回到可用模块；全局搜索不返回不可进入的旧独立笔记。客户跟进记录不受影响。已有书籍、私人笔记和阅读历史保留，手机仍隐藏资料库。
- 电脑文件页右下角增加“+”，点击在当前文件夹中新建文件夹。主页/最近文件中新建到我的文件根目录；客户文件中新建到客户文件分类。按钮随内容区宽高调整边距，不遮挡最后一项；多选、最近删除和单个搜索定位视图不显示，文件操作繁忙时暂不可用。原侧栏“+”保留。
- 文件空白处右键提供新建文件夹、查看、排序、粘贴到此处和刷新。查看有小图标、中图标、列表；排序有修改时间、创建时间、名称、文件类型、大小。选中项带勾选，复用顶部设置及原偏好存储，切换入口不会产生两套设置；文件夹也跟随时间/名称排序。
- 粘贴支持从系统剪贴板导入普通文件，也支持Fly内剪切文件后粘贴移动到当前目录。重复内容沿用跳过/保留副本/替换确认，不静默覆盖。只在主动打开右键菜单或点击粘贴时读取文件路径，不读取文本或其他剪贴板内容。空剪贴板时菜单禁用；目录、失效路径及符号链接不递归导入，并给出提示。本轮未实现从系统剪贴板递归粘贴文件夹，已有Fly文件夹移动功能保留。
- 最近删除的右键菜单保留查看、排序和刷新，不显示新建、粘贴。已有图片/PDF打开、右键文件操作、拖入防重复、多选和文件夹导航保持可用。
