# 手机与电脑文件移动

日期：2026-10-18。分支 `codex/fly-2-sync`；基于文档检查点 `662c2af` 续补源码。版本字段仍为 `2.0.6+42`，schema 19 未变；未重新构建安装包，现有 Windows/Android build 42 不包含本次新入口。

## 操作

- 手机：长按普通图片或文件 → 移动 → 进入目标目录 → 移动到此处。
- 电脑：右键普通图片或文件 → 移动，使用同一个目标目录选择器。
- 支持逐层进入子文件夹、上一级和“我的文件”根目录。移动至根目录的散文件在手机“未分类文件”中访问。
- 取消不改数据；当前位置不能重复确认；目标在选择期间被删除时禁用确认，允许重新选择。
- 文件夹读取提供加载、错误和重试状态，移动失败由现有错误提示反馈，成功显示“文件已移动”。

## 数据与范围

复用 `ManagedFileRepository.move` 和现有同步，仅更改普通文件的 folderId/更新时间。文件 ID、显示名称、实体路径、内容、标签及同步身份保留，不重建实体、不覆盖同名文件。图库和列表使用同一菜单；该入口同样适用于普通 PDF、表格等文件。

保留既有业务附件归属保护：客户、订单和笔记的关联附件不通过此入口搬离所属记录，也不转换成普通文件。客户文件入口中新导入、拍照的普通资料可以移动。

## 同日续补：批量移动

检查确认此前只有单文件移动，多选栏没有移动操作。本次手机与电脑的多选栏均增加“移动”。进入多选、勾选或全选当前结果后，一次选择目标文件夹或“我的文件”根目录；支持来自不同目录的搜索/最近结果。目标选择器显示已选数量，取消保留原选择。

逐项处理时沿用进度条；结果明确成功数量、已在目标目录数量和未移动数量。成功和原地项退出选择，失败项保留，结果“详情”列出每个失败文件的名称及原因。正在处理时禁用重复提交；全部选中项已在目标目录时不能确认。目标失效则报告错误，不能伪装成功。

原地项不更新修改时间、不产生多余同步事件。同名文件仍保留各自实体和身份；未下载的普通文件也可先同步目录分类，实体继续按原同步队列下载。混选客户/订单/笔记等关联附件时提前提示保留归属，逐项结果说明未移动原因，不静默丢弃所选项。

新增数据回归覆盖 27 个文件、同名文件、不同来源目录、原地项、实体/标签保留、同步队列、根目录、空选择、失效目标、删除及各类关联附件保护。原四种尺寸的交互回归增加批量选择、取消、移入多级目录、移回根目录及部分失败保留。局域网回归加入两项文件（含 20 MiB）的批量往返。
