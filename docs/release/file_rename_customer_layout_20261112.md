## 文件名与实际内容

文件管理的重命名现在同时更新Fly管理的磁盘文件、打开路径、文件名称及分享/业务附件显示名称。只输入新名称时保留原扩展名；扩展名未变时保留已知MIME类型。文件内容、摘要、ID、所属记录、标签与逻辑文件夹保持。

遇到现存目标文件、非法名称或文件系统改名失败，不修改记录；数据库写入失败时恢复磁盘旧名称。磁盘操作限定在数据目录内原位置，不覆盖已存在目标；若文件尚未下载，记录新下载名称，防止关联到同目录中不相干的已有内容。导入时产生的Fly管理副本会改名，导入前的外部原件保持。

局域网同步继续只同步业务名称、不传本机绝对路径。另一设备已有实体文件时，根据接收的新名称在原位置改名，不为同一份内容重新下载。历史业务附件的内部存储名称与展示名称本来不同的情况保持兼容。云同步仍不传实体文件。没有修改SQLite20、后台0005、SDK或依赖版本。
