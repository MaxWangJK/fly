# Fly 1.0 最终版 — build35

版本标识：1.0.0+35。安装包：`dist/Fly-Setup-1.0.0-build35.exe`。

## 版本范围

保留 build34 的现有 Dashboard、客户、订单、任务、日历、四象限、文件、笔记、我的聚焦、今日复盘、工具、设置、搜索、备份及授权功能与配色。

资料库不属于 1.0：笔记直接打开个人笔记编辑器，不展示资料库、SOP、官方文章、收藏入口；设置隐藏资料包导入；全局搜索不加载或返回资料库；授权页不展示免费资料库入口；关联笔记不展示资料库跳转按钮。

旧 `/knowledge` 链接在 1.0 重定向个人笔记，保留笔记 ID。已有笔记内容、资料库收藏、文章关联、数据库和磁盘资料均保留，不降级数据库或删除用户数据。

## 2.0 预留

统一编译开关 `ENABLE_KNOWLEDGE_HUB` 默认关闭，无用户可开启选项。未来 2.0 经版本规划和验收后可显式启用，恢复现有资料库实现；1.0 打包明确传入 `false`。
