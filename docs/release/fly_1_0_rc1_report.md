# Fly 1.0.0+23 发布候选版报告

日期：2026-09-30。此包是 **RC（候选版）**，不是已完成签名与销售验收的正式发行版。

## 已完成

- 将现有 Dashboard、客户、订单、任务、日历、四象限、今日复盘、文件、笔记、装柜工具、搜索、设置、备份和离线授权统一纳入 1.0 版本范围与 Git 源码管理。代码基线：`19b711f`。
- 首次运行默认保持空白，演示数据仅在用户主动勾选时加入；既有数据库不会被补入演示数据。
- 自动备份失败不再阻止软件进入；恢复大 ZIP 改为磁盘流处理；禁止将自定义备份目录置于 FlyData 内导致递归备份。
- 修复日历滚轮切换，并清理分析器问题、更新旧测试、增加数据库迁移和备份路径回归测试。
- 发布脚本从 `pubspec.yaml` 读取版本，同次重建应用与安装器，明确启用离线授权，不复用旧版 EXE。

## 构建证据

- `flutter analyze`：零问题。
- `flutter test`：全通过。
- `flutter build windows --release`：成功。
- Windows 安装器：`dist/Fly-Setup-1.0.0-build23.exe`，12,535,144 字节。
- SHA-256：`453CE6351001F025899FBDB4ECD84D09F4469F8E331858F655258A79E0047FC3`；与同目录校验文件一致。
- 安装器和 `fly.exe` 的 Authenticode 状态均为 `NotSigned`。

## 正式销售前仍需完成

1. 在全新 Windows 用户或虚拟机中完成安装、首次启动、三天试用、激活、重启和卸载保留数据的人工验收。
2. 用升级前备份的旧 FlyData 演练数据库迁移、文件附件完整性和回退流程；在隔离数据目录演练包含 `.fly-file-objects` 的备份恢复。
3. 人工走查 1.0 核心业务：客户/订单金额、文件拖入拖出、笔记持久化、今日复盘和装柜方案。装柜计算仅供规划参考。
4. 确定购买后的授权、试用、售后、隐私和第三方软件许可说明；为正式对外分发包配置并验证发布者代码签名。

在以上事项完成前，对外请称为“测试候选版”，不要宣称已完成正式 1.0 商业发行。完整门槛与功能边界分别见 `fly_1_0_release_plan.md` 和 `../product/v1_scope.md`。
