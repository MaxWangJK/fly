# Fly 1.0 发布计划（2026-09-29）

## 版本基线

- 产品版本：`1.0.0`；当前内部构建号：`25`。版本由 `pubspec.yaml` 驱动，构建时传给应用内显示、备份元数据和安装器。
- 基于用户人工验收的 V11 和后续功能；保留现有 FlyData 与已接受的 UI，不以重新设计为发布前提。
- Windows 10/11 x64、离线单用户、本地数据。安装器按用户安装，卸载保留数据目录。
- `dist/`、`artifacts/`、截图输出、私有密钥、调试符号不是源码版本的一部分；新增业务模块、迁移、测试、文档和发布脚本必须进 Git。

## 1.0 功能清单

产品范围参见 [v1_scope.md](../product/v1_scope.md)。源码内一并管理客户/订单、首页、任务/日历/四象限/复盘、文件/笔记、装柜工具、全局搜索、通知、自动备份、离线授权、设置和 Windows 平台适配。旧版 Task/Calendar/Matrix 数据与新模块同库迁移，不新建空库替换旧库。

## 发布门槛

1. `dart format` 后无非预期改动；`flutter analyze` 零问题；`flutter test` 全通过；迁移和备份恢复必须有隔离数据测试。
2. `scripts/build_windows_release.ps1` 从当前源码构建当前 `pubspec.yaml` 版本，显示与备份元数据一致，且明确启用离线授权；不能将未启用授权的开发构建误打包。
3. `scripts/build_installer.ps1` 必须在同一次运行中重新构建，检查来源、输出文件和 SHA256；不能悄悄复用旧版 EXE。
4. 在干净 Windows 用户环境中试装、激活、创建空白数据目录、导入/保存、重启、升级、卸载后确认 FlyData 保留。已有数据库做升级前备份，然后校验迁移、原数据及附件。
5. 在隔离测试数据目录演练自动备份、手动备份、含 `.fly-file-objects` 的复制和恢复；模拟备份目录失效时仍应进入应用并看到提醒。
6. 人工复核 CRM/订单金额与附件、今日复盘、文件拖入/拖出、笔记保存、通知、装柜人工摆放与方案保存。3D 结果不得宣传为实际装柜保证。
7. 发布者确认收费授权/试用/售后条款、隐私说明、第三方许可、Inno Setup 商用许可决策与 Authenticode 签名证书。没有签名证书的包只能标为未签名候选包，不宣称已完成可售发行。

## 外部依赖与剩余风险

- 本仓库没有代码签名证书；签名和 SmartScreen 声誉需要发布者配置与验证。
- 1.0 不承诺云同步和移动端；大文件备份依赖外置对象仓库，不能只复制 ZIP。
- 首次运行默认不插入演示客户/订单/任务，用户可显式选择演示数据。
- 软件许可证/激活策略的商业条款由发布者确定；发布脚本仅保证代码中的离线授权功能已启用。

只有以上发布门槛全部满足，才将构建产物标记为 Fly 1.0 正式可售版本。任何未完成项都应在交付报告中逐项说明，不以“功能大体符合”替代发布验收。
