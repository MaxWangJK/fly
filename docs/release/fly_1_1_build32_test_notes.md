# Fly 1.1.0+32（2026-10-08）

## 本轮变化

- 任务按优先级从高到低排序：高、中、低、无优先级；已完成任务仍置后。
- 修改优先级后，列表随保存自动更新；今天、最近 7 天、收集箱、自定义清单均使用相同规则。
- 搜索结果及今天页面的逾期任务也以优先级为首要顺序；同级搜索结果保留最近修改优先，同级逾期任务保留原日期顺序。
- 手动拖动仅调整同优先级、同状态任务之间的顺序，不会覆盖优先级设置。
- Dashboard 恢复 build28 的“当前工作分布”：今天需跟进客户、今天任务、待收款订单、紧急订单、重要且紧急；保留五项指标和客户/订单摘要。
- “我的聚焦”继续位于任务模块的“今日复盘”下方，新增“本月重点”，顺序为人生主线、本月重点、本周重点、今日提醒。
- 本月重点沿用已有聚焦数据保存与修改历史规则，不会按月份自动清空。
- 安装包继续包含 V12 资料库和已有业务模块；本轮排序与聚焦修改不需要新增数据库迁移。

## 人工验收

1. 同一清单创建至少四个任务，分别设为无、低、中、高优先级，确认高优先级位于最前。
2. 保持列表打开，将一个低优先级任务改为高，确认自动调整位置；再改为无，确认移动至低优先级任务之后。
3. 在今天、最近 7 天、收集箱、自定义清单和搜索结果中检查优先级顺序；今天的逾期分组也应高优先级在前。
4. 拖动同级任务并重新进入清单，确认同级顺序保留；跨等级拖动应继续遵循优先级，已完成任务仍置后。
5. Dashboard 检查五类工作分布数量以及点击跳转；小窗口下可横向查看分布图。
6. 在“我的聚焦”编辑本月重点，切换页面和重启后确认内容保存，修改后可查看历史。
7. 升级安装后检查原有客户、订单、任务、复盘、文件、笔记、资料库和装柜方案数据。
