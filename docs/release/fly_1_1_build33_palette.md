# Fly 1.1.0+33 — 青霭雅灰

## 配色调整

- 根据用户提供的高级灰色卡新增“青霭雅灰 / Sage Mist”。
- 一级导航采用参考青绿灰 `#97A791`，二级目录为浅灰绿，页面画布为暖灰白，笔记列表为浅雾蓝，文件浏览区、正文与编辑区为暖白。
- 按钮和选中图标使用加深的青绿色，辅助信息采用雾蓝、灰紫与暖米色；正文保持深灰绿，避免直接将浅色卡用于小字号文字。
- 深色模式采用灰绿背景、雾蓝灰列表、浅青绿色强调，并调整按钮文字对比度。
- 移除“石墨”选项；旧的 `colorPalette=graphite` 设置自动解释为 `sageMist`，下次主动选择配色时按新名称保存。
- 其他配色方案和业务功能保持原有行为。

## 人工验收

1. 设置 → 外观：确认显示青霭雅灰，不再显示石墨。
2. 选择青霭雅灰，检查导航、客户、订单、任务、Dashboard、文件和资料库的颜色；重点确认文件目录、文件列表及笔记目录、笔记列表、编辑区的层次。
3. 重新启动，确认选择保留；使用旧石墨设置升级时，应自动呈现新配色。
4. 切换深色模式，检查输入框、按钮、选中项及正文是否清楚。
5. 切回原有配色，确认原有外观正常。
