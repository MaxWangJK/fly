# Fly 1.1.0 build34 — 我的聚焦编辑优化

## 修改范围

- 人生主线、本月重点、本周重点、今日提醒：普通回车用于换行，不再直接保存。
- 点击编辑框外部，或通过键盘切换焦点后自动保存。仅移动鼠标不提交内容，避免误触。
- 编辑框按内容自动增高，保存后的正文完整换行展示，取消原来的三行截断。
- 保留原有 800 字限制、Ctrl+Enter 保存和 Esc 取消；取消编辑不会触发失焦保存。
- 保存时暂时锁定当前输入，失败后保留草稿并显示错误。原有历史记录、配色和数据结构不变。

## 人工体验清单

1. 打开任务 → 我的聚焦，分别编辑四个框，回车应换行并继续编辑。
2. 点击编辑框外部或按 Tab 切换焦点，重新进入后内容应仍在。
3. 粘贴多段内容，编辑中和保存后均应自动增高；页面可滚动查看完整内容。
4. 缩窄窗口、切换浅色或深色配色，检查内容换行和边距。
5. Esc 取消修改后仍为原内容；修改并保存后，旧内容继续保留在聚焦历史。
