# Fly 2.0.4 build 40：复盘刷新与手机快捷操作

2026-10-16 接续说明：本页记录 2026-10-14 的测试包及历史验证；本版源码现已纳入本次本地检查点，随后对同一程序增加正式安卓签名备案包。下文“未正式签名”仅指原测试包；各包信息和签名区别见 [APK 台账](../handoff/APK_RELEASES.md)。

2026-10-14，2.0 分支 `codex/fly-2-sync`，schema 19；保留 1.0 master。包含此前 build 39 的座右铭、书籍导入与阅读功能。本轮没有推送或部署，源码仍包含未提交的工作区改动。

## 本轮变化

- 电脑复盘编辑页监听当前日期的复盘数据；收到手机同步内容后立即更新输入框，清空的答案也会刷新。正在本机保存或保存失败的字段保留待保存输入，不被异步通知覆盖。
- 手机客户、任务的新增入口移到右下角“＋”。新任务只填名称，在当前清单创建；今天视图创建的任务带今天日期，全部任务/收集箱默认放到收集箱。
- 手机任务、客户、订单、文件的搜索从右下角放大镜展开；输入框只筛选，不承担创建功能。关闭搜索清空查询。搜索按钮位于新增按钮上方。
- 手机订单“＋”先选择客户再创建，随后打开订单详情；文件“＋”集中导入、拍照和新建文件夹。
- 手机任务完成动画保留，“撤销”提示在 4 秒后自动收起；期间可撤销，连续完成时替换上一条提示。
- 手机任务导航依次为今天、清单、复盘、日历、四象限。清单下方直接展示全部任务、收集箱和各级自定义清单，选择后显示任务及简短路径；管理清单仍可新建子清单。

## 交付与验收

构建结果与校验值在 `dist/manifest-Fly-2.0.4-build40.json`；Windows 安装版和便携版、Android 通用 APK 为功能测试包，沿用原测试授权设置及 Android 签名。书籍导入使用原密钥，原 `.fly` 手册仍可导入。Apple 平台本轮不打包。

人工验收建议：同时打开电脑和手机复盘，手机修改当前日期答案并同步，电脑编辑页应直接展示；手机切自定义子清单点“＋”添加任务，确认归属；搜索输入任意不存在名称并提交，应只有空结果，不能生成任务或客户；完成任务后等待 4 秒，撤销提示应收起；分别检查竖屏、横屏的快捷按钮及列表末尾。
