# Fly 2.0.5 build 41：安卓适配与文件夹首页

2026-10-17；分支 `codex/fly-2-sync`，源码 2.0.5+41，数据库 schema 19。沿用原安卓签名身份和文件/业务数据；Windows 现成安装包仍为 build 40。本轮源码及之前内部授权工具属于 `24afa8d` 之后的工作区修改。

## 本轮变化

- Android 使用全屏延伸背景和系统安全区域，原生允许在切口区域绘制，交互避开挖孔、刘海和横屏侧边摄像头；明暗主题同步调整系统栏图标。
- 手机新增和搜索按钮统一 56×56，竖屏底部间距改为 36，横屏保留 16。列表末尾增加可滚动空间。
- 清单筛选分行展示全部/收集箱及自定义层级，超出区域可纵向滚动。已验证同步记录到达后，任务目录和文件夹能即时刷新；没有造同名演示清单。
- 手机日历继续默认周视图，保留周/月、拖动改期和既有撤销能力。
- 文件页默认进入文件夹首页，展示客户文件和电脑“我的文件”下的一级文件夹。顶部保留搜索，右上角菜单集中视图、排序、图片/文件优先、多选和最近删除。保留拍照、批量分享/删除、系统打开及图片查看器。
- 长按客户文件可在本机移除入口，菜单可恢复；不会删除客户或附件，不生成同步删除。普通文件夹的真实删除仍会同步，最近删除保留文件夹恢复。
- 原散放在文件根目录的内容通过虚拟“未分类文件”入口访问，不移动实体，也不丢弃历史导入文件。每次进入文件页从首页开始，仍记住视图和排序。
- 同步设置直接显示电脑服务/手机扫码，不展示两种模式的选择卡或云同步表单；启动不自动连接隐藏的云模式，原配置及账户数据保留。右上角连接按钮直接打开同步设置，状态详情仍可执行立即同步/重连。

## 真机验收

1. 在实际挖孔/刘海/长条摄像头设备检查竖屏和横屏背景是否延伸、同步按钮和底部导航是否避开切口及手势区；检查三键导航、深色模式、键盘弹出。
2. 电脑开启同步服务后扫码；检查任务目录、light/door/panel 等文件夹及其中实体文件。绿色连接不能代替文件队列和可打开检查。
3. 手机隐藏客户文件后，电脑客户、文件和附件应保持完整；手机重启仍隐藏，菜单可恢复。
4. 检查文件夹新增、返回、搜索、相册/列表切换、批量分享/删除、最近删除恢复、真实相机与系统打开。

Android 全屏实现遵循 [Flutter SystemUiMode](https://api.flutter.dev/flutter/services/SystemChrome/setEnabledSystemUIMode.html) 与 [Android 切口支持](https://developer.android.com/develop/ui/views/layout/display-cutout?hl=en)。背景绘制与交互安全区分别处理，不能以桌面模拟渲染替代所有厂商真机验收。
