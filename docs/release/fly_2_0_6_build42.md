# Fly 2.0.6 build 42：客户文件新增与复盘卡片

2026-10-17；`codex/fly-2-sync` 工作区，schema 19。本轮与之前 build 41、内部授权工具均为 `24afa8d` 之后的未提交修改，1.0 基线保持不变。

## 行为变化

- 手机打开客户文件后保留右下角“＋”，支持导入、拍照、新建子文件夹，子目录可正常返回。新增普通资料存入稳定 ID 的真实同步文件夹，电脑“我的文件”也可访问；原客户/订单附件仍保留业务归属。手机首页仅显示一个虚拟客户文件入口，不重复列出其内部资料根目录。隐藏入口仍是本机偏好，不同步删除。
- 文件夹网格根据可用宽度调整：常见手机每排至少三个，小于约 348 逻辑像素的窄屏保留两个，宽屏增加至最多六个。列表模式保留。
- 手机“我的”移除账户设置入口，保留常规设置和电脑同步设置。
- 手机与电脑的今日复盘使用一张文章式卡片。空答案显示输入框；已有答案显示文字，点击可继续编辑。点击完成或焦点移开后收起输入框，输入过程中自动保存不会打断编辑；保留多行、清空、日期切换、历史记录、同步刷新和保存失败重试。
