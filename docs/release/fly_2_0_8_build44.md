# Fly 2.0.8 build44：客户、文件与账号同步交互

2026-11-01；SQLite schema20、后台迁移0004，分支 `codex/fly-2-sync`，1.0 基线不变。本轮按用户授权保存全部公开工作区，包含此前账号生命周期、原生 Ubuntu 部署及官网下载页改动。安装包、业务数据和私有配置仍不进入 Git。

## 本轮实现

- 两端右下角加号打开同一客户对话框。姓名、国家、级别、状态必填，级别/状态直接单选；来源选填，标签快捷选择或输入新增。客户和来源/级别关联原子保存，重复姓名不会留下半条记录。
- 状态固定为新客户、开发中、意向客户、成交客户、复购客户。旧询价/跟进归开发中，报价/寄样归意向，其他旧自定义状态归开发中；原数据库记录与状态 ID 保留。旧排序、停用不影响五阶段顺序。
- 手机客户与订单只有一组表头，数据按列对齐，每行不重复字段名；点击行仍为底部详情。
- 基础复盘保留原四组、总结、失焦收起输入和历史卡片；只把方案切换缩为小图标。航向方案和已存答案继续保留。
- 桌面“我的文件”改为当前层平面浏览，点击文件夹进入、面包屑返回；空白处右键可新建文件夹。保留多层目录实体、三种文件视图、单个/批量移动及既有附件保护。
- 设置新增“我的”：本机名字/头像、云登录邮箱、注册登录及找回/修改密码、注销。头像等比缩放后保存，本机资料不进入云同步。可选自建地址首次为空，保存后替代默认服务，可恢复默认；界面不展示系统默认域名。
- 同步页聚焦本地/云方式、配对与状态，隐藏云地址、邮箱和空间 ID。首次本地默认开启，电脑显示二维码供手机扫描；切换先确认断开当前服务，取消保持状态。开启云同步未登录时转到“我的”，已登录直接启动原同步引擎；切回本地恢复配对。

云端继续只同步结构化记录及文件元数据，不传图片或文件内容；本地配对继续同步实体。保留三设备字段合并、前台立即同步、写入触发、WebSocket 提醒和五分钟补查。手机进入后台不保证常驻；系统后台推送与收费仍未接入。

账号找回/注销需要自行更新后台至 `0004`，旧 build43 后台包不包含这些接口。优先使用 [PostgreSQL + Python 原生部署](../../server/deploy/ubuntu-native.md)，既有 Nginx/PHP 和证书不变。本机未部署生产服务或发送真实邮件。

## 安装与兼容

Windows 10/11 x64；Android 7.0+、minSdk24、targetSdk36。测试包保持 `ENABLE_LOCAL_LICENSE=false`，沿用原书籍配置和长期安卓正式/测试证书。正式签名与原测试签名不能互相覆盖，按现有安装身份选择 APK。升级前保留完整业务及实体文件备份；不要让旧 build42 打开 schema20 目录。

Windows 安装器未作发行代码签名。扫码、头像系统选图、相机、外部打开、系统分享仍需实际设备验收；本轮不包含 Apple 构建、Ubuntu/systemd 或生产 PostgreSQL 并发验收。
