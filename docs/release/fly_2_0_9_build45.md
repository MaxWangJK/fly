# Fly 2.0.9 build45：客户右键开单与统一文件夹视图

2026-11-02。分支`codex/fly-2-sync`，SQLite schema20、后台API及迁移0004不变。本轮只修改客户端，后台无需因本次功能升级。

- 电脑客户列表右键，“新建订单”位于“删除客户”上方。弹框展示对应客户，PI发票号必填并作为订单号，订单状态直接单选、默认待付款；取消不建单。成功后选中并打开对应客户的订单，不需要再次选客户。
- PI去首尾空格、最多120字符，重复号码（不区分英文大小写）提示并保留输入。客户校验、号码检查及插入处于同一事务；删除客户不能继续建单，不留下部分订单。
- 订单状态固定六种及顺序：待付款、生产中、待发货、已发货、已完成、已取消。沿用原稳定状态ID，旧询价/确认/下单/待尾款或自定义状态显示为待付款，已收尾款显示为待发货；原数据库状态、订单和财务记录不删。旧排序、停用及软删除不影响六阶段选择；之后编辑订单保存规范状态。
- 文件首次或偏好失效时默认小图标，保留用户已保存的视图。电脑文件夹随小图标、中图标、列表一起切换；点击进入和右键管理保留，文件夹仍按当前层平面浏览。手机已有文件夹图标首页及相册行为保留。

保留build44的客户新建、个人资料、基础复盘、互斥同步与账户功能；云端不上传图片/实体文件。测试包继续关闭本地授权拦截，复用原书籍配置和原安卓正式/测试签名。Windows安装器未作发行代码签名；扫码、选图、分享及Apple平台仍待真实设备验收。
