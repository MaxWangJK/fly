# Fly V12 资料库构建记录（2026-10-07）

## 交付内容

- 一级导航中的“笔记”升级为“资料库”，原有笔记、目录、标签、图片和附件继续保留在“我的笔记”，并沿用原数据。
- 新增只读的 Fly 外贸资料：多层目录、今日精选、交互式 SOP 地图、搜索、标签、收藏和 14 篇原创演示文章。
- 官方文章以 Markdown/front matter 为源，编译为适配 Fly 配色的安全 HTML；支持提示、警示、示例、话术、步骤、图片、表格、目录和内部跳转。
- 文章可关联个人笔记，但不会将官方全文复制到笔记。全局搜索分别呈现资料和我的笔记。
- 开发者构建支持编辑、插图/截图粘贴、预览及签名 `.flykb` 导出；普通构建只允许验证签名后导入。失败的导入保留当前资料包及个人笔记。
- 当前演示文章均为免费内容；本地授权到期后仍可阅读免费官方资料，个人笔记仍受现有授权控制。

## 建议人工验收

1. 在已有笔记的电脑升级安装：检查“我的笔记”的内容、目录、标签、图片和附件均未变化。
2. 在不同配色下查看资料首页、SOP 地图、文章正文、图片预览和目录跳转；确认普通构建没有编辑入口。
3. 搜索“报价”“催款”等词，分别从资料库搜索和 Ctrl+K 打开文章；收藏后重启检查状态。
4. 从官方文章创建个人笔记，输入私人内容并返回来源文章；确认官方正文未被复制。
5. 在独立测试数据目录导出、导入 `.flykb`，核对目录、文章、图片、排序和标签；用被改动或旧版本资料包确认拒绝导入且旧资料不变。
6. 在授权到期的测试环境确认免费资料可读，而“我的笔记”继续按现有授权规则处理。

## 发布注意

- 本轮只验证 Windows；macOS、Android 和 iOS 的 WebView 实机兼容性尚未验收。
- 普通复制限制不是 DRM，不能阻止截图、OCR 或本地高级访问。
- 安装器编译器输出 `Non-commercial use only`。销售分发前须确认 Inno Setup 的适用许可；安装包也尚未配置代码签名。不要把本次构建通过等同于商业发行验收。
- 开发者签名私钥仅保存在 Git 忽略目录，未包含在安装包中；必须另行安全备份。详见 [资料包发布流程](../knowledge/publishing.md)。
