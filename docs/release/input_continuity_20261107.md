# Fly 2.0.14+50 输入连续性修复

用户要求检查整个软件输入框：输入途中失去焦点、必须重新点击；连续输入15却将1选中后替换成5。

## 原因与修改

- 客户资料、自定义字段、订单金额与汇率原来用当前内容作为控件标识，自动保存改变内容后会销毁编辑器。现在按记录及字段保持标识，切换记录才重建，避免混入上一条记录的草稿。
- 装柜数量等输入在模型回传时重复设置文字，可能重置光标、选区与中文输入状态。统一跳过相同文字回填；接受外部变化时保留合法光标和选区，中文组词期间不打断输入。
- 手机搜索在其他界面状态刷新时可能收到旧搜索词。现在不让未变化或延迟的旧值覆盖正在输入的内容，清空按钮仍立即清空。
- 任务、基础/航向复盘、笔记的自动刷新保留已有编辑界面；笔记表格及装柜高度使用持续存在的编辑器。个人设置在首次加载完成前禁用相应输入，避免初始化覆盖新草稿。

全库静态检查输入入口、内容相关标识、控制器回填和快捷键。保留主动选择建议、切换记录、明确完成编辑等操作；复盘仍在完成或离开输入框后显示答案卡片。无数据库迁移、同步协议或后台变更。
