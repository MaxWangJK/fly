# Windows 2.0.15+51：手动排数完整单组展示

用户提供40HQ截图：推荐每排8件、26层，输入12×20后合计240件，剖面却显示PVC160件和48件，3D仅显示208件。要求按手动数据绘制，允许超出柜体，不拆为两组；本轮只打包Windows。

## 原因及行为

旧流程将手动排数当作自动装柜的上限：柜宽2200mm、每件宽250mm，最多每排8件；先放8×20=160件，再在上方剩余高度中追加8×6=48件，剩下32件未摆放。

现在，明确编辑每排数量/层数后，会保存“手动整组排布”规则。12×20按一组240件生成，使用2900×3000×2000mm的实际尺寸；比柜宽多出的800mm保留，剖面及3D使用同一组几何，越界标红并显示提示。推荐8×26、理论容量208仍作为参考。实际摆放数量/重量按240件计算；这不是对实际装载可行性的确认。

清空任一数字按0件处理，重新输入恢复一组；保存重开、改朝向及重新计算继续保留手动整组排布。新规则保存在已有layoutV3 JSON中，旧方案没有标记时保持原自动/人工坐标，不自动改写历史方案。要更新旧截图中的方案，请重新填写12与20。自动装柜的尺寸/重量限制与部分尾排绘制保持原规则。

SQLite20及后台0004不变。只构建Windows安装器和便携包，安卓最新仍为2.0.14+50，本轮不构建安卓或Apple，不部署后台。原网站与独立书稿工作区保留。
