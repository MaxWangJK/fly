## 新增完成的代码

- Excel 客户、订单、产品、收款、成本表头使用导出时选择的界面语言；原业务内容、分类名称和数值保留。
- 客户导入模板支持英文表头与英文示例；导入映射识别 Customer status / Customer source。
- 导出失败提供提示，不再将失败当成成功导出。

- 分类仅改变显示文本；保存的分类值不随语言变化，避免破坏查询、历史记录或金额汇总。

## 本轮人工测试

1. 中文和英文分别导出全部数据及当前筛选数据，检查五个 Sheet 的表头；客户名称、状态、标签、备注及金额保持原内容。
2. 下载英文模板并重新导入，姓名、公司、状态、来源、优先级等自动映射到正确字段；示例数据只在确认导入后创建。
3. 用不可写位置导出，检查失败提示；取消文件选择不产生成功提示。
4. 删除被多个客户/订单使用的标签，确认弹窗的数量、影响范围和语言；取消不修改数据。
5. 删除有订单的客户，确认说明订单保留；删除/恢复后关联订单仍在。
6. 客户重复提醒中的真实名称保持原文；订单详情、订单统计、编辑过的备注和跟进记录在两种语言下显示一致。
7. 切换附件分类，再切换语言和重开详情；分类仍指向同一个存储值，文件仍能打开。
8. 安装前保存并备份，关闭旧 Fly；升级后执行第 14 版清单中的任务、复盘、文件、笔记、装柜和离线授权项目。
