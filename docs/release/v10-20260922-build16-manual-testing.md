## 人工测试重点

1. **导航及首页**：中文/英文切换后检查图标提示、窄窗口底部导航、空详情、首页五张卡片和缺汇率说明。真实数据不变化。
2. **全局搜索**：客户、订单、任务、文件、笔记和标签搜索；分组、空结果、键盘说明与当前语言一致；结果名称、匹配内容及跳转正确。
3. **装柜汇总**：复制汇总到记事本，检查分节名称、已放/未装、载重、超量警告；切语言前后数值完全一致。超量确认/取消与保存重开仍正常。
4. **服务错误**：用测试副本触发同名文件夹、非法标题、已删除记录、源文件丢失等情况。英文错误应能理解，文件路径仍正确；未知平台错误不可被错误地替换成成功提示。
5. **备份恢复**：仅用隔离测试目录，缺文件对象或无效备份应拒绝并显示原因，不覆盖业务数据。
6. **笔记草稿**：模拟不可写后保留草稿，切页面、恢复及重试不丢文字；失败提示支持两种语言。
7. **通知**：分别在中文/英文下配置任务、客户跟进、订单交期提醒，检查 Windows 通知标题和今天/明天/昨天日期；关闭复盘提醒时，其他三类提醒的语言仍正确。
8. **全量验收**：继续执行 `v10-20260921-manual-testing.md` 的任务、日历、矩阵、CRM、订单、文件、笔记、3D 暂存/跨节/超尺寸、授权和升级项目。
