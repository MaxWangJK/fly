# Fly V10 开发预览版：人工测试清单

日期：2026-09-13。此包不是 V10 最终验收版。
本轮按用户要求没有运行 flutter analyze、单元测试或回归测试。
编译和安装包生成仅说明产物可生成，不代表下面的功能已通过验收。

## 使用前

- 先在现有版本中备份数据库和附件目录，保留备份原件。
- 建议选择一份复制的 FlyData 做人工测试，不直接用唯一业务数据。
- 安装前保存并关闭旧 Fly；不要在未保存时覆盖或关闭窗口。
- 本次数据库升级到版本 14，只增加笔记排序字段，未删除旧表。
- 不要直接用旧版程序打开已经升级的数据；回退请使用升级前备份。

## 本次重点测试

### 文件

- 客户文件同时显示客户附件、订单 PI/CI/PL/CO、收款附件和费用附件。
- 同一文件不重复；删除客户/订单后不出现失效关联，但附件原件保留。
- 点击预览中的客户、订单标签，进入正确详情；订单列表不残留其他客户筛选。
- 客户标签筛选实时使用客户标签，不把关系名称复制成文件标签。
- 隐藏 CRM 后客户文件入口隐藏，重新启用后数据仍在。
- 小图标、中图标、单行列表切换保留选中项；窄窗口可滚动查看列。
- JPG/PNG/WEBP 缩略图与图片预览能显示真实图像，损坏图片有提示。
- PDF/Office 的系统打开、文件拖出、复制到资源管理器/微信由人工确认。

### 笔记

- 列表仅显示标题，不再用正文摘要或时间占多行；默认按创建时间倒序。
- 在普通文件夹、无搜索条件时，上移/下移改变该文件夹内顺序，重启后保留。
- 最近/收藏保持创建时间排序，不展示含糊的文件夹排序操作。
- 移动笔记到另一个文件夹后，不沿用旧文件夹的排序编号。
- 标题与标签搜索准确；底部标签添加、移除不删除其他笔记的标签关系。
- 编辑器显示创建时间、修改时间；正文和标题字号更紧凑。
- 空正文输入 `/` 弹出菜单；选择标题、列表、清单、表格、图片和附件后可保存。
- 新建菜单没有引用和代码块；旧笔记已有引用/代码内容仍可显示、编辑和保存。
- 取消菜单不会丢掉原内容；自动保存失败后重试和切换笔记不丢草稿。

### 任务、复盘和已有模块

- 跨日任务在 Today、日历一致展示；逾期任务不消失，顺延只修改截止日期。
- 今日复盘按日期分别保存；提醒默认关闭，启用后按设置时间提醒且每天不重复。
- 客户、订单、任务、日历、四象限、备份、文件导入、装柜方案保存保持原功能。
- Alt 左右、上下拖动旋转按新方向跟随操作；普通平移、缩放保持原方式。
- 确认旧数据库升级后，客户、订单、笔记、文件和装柜方案数量与内容完整。
