# Fly V11 · 全部人工验收清单

目标版本：1.0.11+17。以下全部为待人工测试项，不代表已测试通过。

## 0. 测试前准备与数据安全

- [ ] 在旧版保存当前工作，做完整备份，包含数据库和附件/文件目录；记录备份位置。
- [ ] 关闭旧 Fly 后安装新版；关于页面显示 1.0.11+17。
- [ ] 首次启动成功完成升级，客户、订单、任务、笔记、文件和装柜方案数量及内容与升级前一致。
- [ ] 再次退出/重开后无重复迁移、重复标签或数据丢失。
- [ ] 用测试数据操作删除/撤销/移动；回退旧版时恢复完整备份，不直接降级数据库。

## 1. 客户快速跟进

- [ ] 今天未跟进的客户勾选一次：变灰、排到已跟进区域，出现约两秒反馈，新增一条跟进。
- [ ] 再次点击：只撤销本次快捷跟进，恢复上次和下次日期，出现取消反馈。
- [ ] 每天/每周重复客户：完成推进一天/一周；撤销恢复原日期；再次完成只推进一次。
- [ ] 快速连续点击：不产生重复记录或双重推进。
- [ ] 完成后关闭重开：当天仍可安全撤销。
- [ ] 完成后手工新增或修改跟进：再次勾选应提示不能安全撤销，不删除手工记录。
- [ ] 手工跟进已完成的客户，没有快捷事件时不允许直接删除手工记录。
- [ ] 第二天不撤销前一天的快捷事件。
- [ ] D 级目录创建客户自动归 D；创建已有 Jack 的 ` jack ` 被拦截，能定位已有客户。
- [ ] 基本信息默认展开，来源可以直接输入文本，保存和重开不丢失。

## 2. 标签隔离与历史关联

- [ ] 客户选择器有客户级别标签，订单选择器没有自动出现这些标签。
- [ ] 在客户和订单分别创建同名 WPC，互相重命名、停用、删除不影响另一域。
- [ ] 升级前同时用于客户/订单的标签，升级后两边都保留关联，但定义独立。
- [ ] 原任务和笔记标签保留，笔记新建标签不进入客户/订单选择器。
- [ ] 客户级别改名仍同步其客户标签，订单同名标签不跟着变化。
- [ ] 标签筛选、移除关系、删除定义和软删除对象恢复行为正常。

## 3. 客户文件与文件浏览

- [ ] 客户附件、订单 PI/CI/PL/CO、收款凭证和成本附件均能在客户文件集合找到。
- [ ] 订单文件显示客户和订单关系，例如 `[Jack] [001]`；客户自己的文件只显示 `[Jack]`。
- [ ] 不自动展示 A级/菲律宾/WPC 客户业务标签；文件自己加的标签仍显示。
- [ ] 点击客户/订单关系直接定位对应详情；筛选和搜索仍能匹配真实关联。
- [ ] 小图标约 36px、中图标约 72px；列表紧凑单行，长文件名可辨认。
- [ ] JPG/JPEG/PNG/WEBP/GIF 缩略图；再次打开目录不反复生成缓存。
- [ ] 单击右侧预览、双击系统打开；PDF/Office/视频至少提供类型、信息及系统打开入口。
- [ ] 箭头只展开树，名称选择目录；多级目录、重命名、包含子目录筛选正常。
- [ ] 文件软删除/恢复、重名导入选择、较大文件进度和取消仍正常。

## 4. Windows 文件传输（重点人工）

- [ ] 从文件图标或名称普通拖动到资源管理器、桌面，副本可打开，Fly 原件保留。
- [ ] 从客户文件集合拖出也正常。
- [ ] 拖到通讯应用、WhatsApp Desktop 聊天输入框，支持的客户端接收为附件。
- [ ] 拖动按 Esc 取消，不丢失文件；不要发送真实客户资料作为测试。
- [ ] 长按后拖到 Fly 内文件夹进行内部移动；单击、双击、右键不受干扰。
- [ ] Ctrl+C / Ctrl+V 文件复制与“复制路径”分别正常。

## 5. Tasks / Matrix

- [ ] start≤今天≤due 的未完成任务进入 Today；只有 start 的只在当天，只有 due 的按截止日期。
- [ ] 已完成不进入 Today/Overdue；逾期列表仍可见，最近过期的在最上方。
- [ ] 全部/单个顺延到今天：只改截止日期，保留历史开始日期。
- [ ] 任务右键不含 Priority/Move to List；日历和四象限的逾期任务也能顺延。
- [ ] 四象限的勾选框、任务标题和创建时间对齐，完成/拖动/筛选行为保留。

## 6. Calendar

- [ ] 起止覆盖今天的跨日任务只在今天显示一次，其他日期不铺满。
- [ ] 未来跨日任务只在开始日；过期未完成任务只在截止日。
- [ ] 完成后只在完成日期显示并划线；取消完成恢复未完成投影。
- [ ] 单日、仅开始日期、仅截止日期任务正常；无日期任务不凭空出现在日历。
- [ ] 同一天 20 条任务可滚轮滚到底；在任务区域空白处左键拖动可滚动，点击任务仍打开。
- [ ] 月/周切换，周一至周日 7 列，前后周、今天和日期跳转正常。
- [ ] 跨月、跨年周不漏任务；跨过午夜或电脑休眠至次日后，进行中任务转到新今天。
- [ ] 五套配色及深浅主题的背景、日期格、周末、选择、今天和任务色协调。
