# V11 build19 — 人工摆放货物数量编辑

## 修改

- 人工摆放分节中同时展示柜内货物和属于该分节的柜外暂存货物。
- 每个实际货物块提供每排数量、层数；合计数量与毫米尺寸同步显示。
- 修改实际货物块的宽度、高度、数量，不重新排列其他货物；沿柜长列数保持不变。
- 柜外左侧暂存货物扩宽时保持靠柜一侧边缘不变，避免扩宽使其意外进入柜内。
- 尺寸变更保留碰撞检查；柜内还检查柜体和分节边界。拒绝变更时保留原尺寸并显示提示。
- 货物从柜外拖入分节后自动展开该分节剖面；可以手动收起。
- 尺寸变更支持撤销/重做，使用既有货物组字段保存，无数据库迁移。

## 人工测试清单

1. 打开旧方案，将已有货物移至柜外，在第一节添加 PVC ceiling：应显示柜外暂存标记和可编辑的每排数量、层数。
2. 将 1×1 改为 4×10：合计为 40，3D 宽、高及尺寸说明随之改变，其他货物的位置不变。
3. 再减少数量：合计与未装数量同步减少，不保留旧数量产生的虚假未装数。
4. 将暂存货物拖入第一节：显示剖面图，并且每排数量、层数仍可编辑。
5. 收起剖面，再拖入另一个暂存货物：剖面重新展开。
6. 在柜内改为放不下或与其他货物重叠的尺寸：显示未应用提示，原摆放保留；移动到足够空间后重新输入应成功。
7. 依次撤销/重做数量修改：3D、输入框、合计及剖面同步恢复。
8. 保存方案并重新打开：数量、尺寸、柜内/柜外位置保持。
9. 对旋转过的货物修改每排数量、层数，确认沿当前宽、高方向变化。
10. 清空输入或输入 0：原货物不消失，显示提示，重新输入正整数可继续编辑。

仅格式化及 Windows Release 编译、安装包打包；按用户要求未执行分析器、自动化测试或应用内回归，未安装或启动应用。
