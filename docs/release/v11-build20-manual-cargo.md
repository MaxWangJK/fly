# V11 build20 — 分节归属、实时尺寸与拖动

## 改动

- 分节列表仅显示实际归属于本节的货物。拖出柜外后移除分节显示，货物本身保留在场景和独立柜外列表，不删除用户货物。
- 删除“暂存”产品概念；柜外列表支持数量编辑，可拖回任意分节。
- 人工模式从分节添加货物时，新货物直接放在所选分节起点，不移动其他货物。
- 每排数量和层数输入正整数后实时应用数量、尺寸、3D 与剖面。扩大靠边货物时仅调整当前货物使其尽量位于本节内。
- 不再将尺寸碰撞误报为无效整数。超尺寸、重叠或堆叠限制改为可见警告，不表示装柜安全验证通过。
- 拖动命中对象在鼠标按下时确定，避免超过拖动阈值后才命中导致细长货物漏选。

## 人工检查

1. 将第一节货物完全拖出柜体：第一节条目和剖面不再显示它；独立柜外列表仍可找到、编辑它。
2. 在人工模式的第一节添加 PVC：直接显示在第一节，未强制进入柜外。
3. 在空的 20GP 第一节，将 PVC 从 1×1 改为 8×10：合计应为 80，尺寸 2900×2000×1000 mm，3D 和剖面同步变化。
4. 将细长 PVC 移到柜边后修改为 8×10：当前货物向柜内贴齐，其他货物不移动。
5. 输入造成碰撞或超过空间的数量：仍应用实际尺寸并警告；通过修改数量或移动当前货物解除冲突。不得将警告理解为已验证可实际装载。
6. 连续一次按住拖动细长货物、普通货物、柜外货物，无需先多次点击。Shift 平移、Alt 旋转保持原用法。
7. 拖回第一节/第二节：只显示在目标分节，剖面展开，数量可继续修改。
8. 撤销/重做尺寸和拖动，然后保存、重新打开方案，检查数量和位置。

按用户要求不运行自动化测试或应用内回归；执行格式化、Release 编译与打包，交由用户人工验收。
