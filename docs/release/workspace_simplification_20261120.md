# 任务详情与客户/订单界面简化

日期：2026-11-20。分支 `codex/fly-2-sync`。本轮为源码修改，尚未新增安装包或提交Git；最近成品仍为2.0.30+66，不包含本轮或同日上一轮财务附件修改。

## 行为

- 任务补充说明框：默认最少行数7→3，最大展开行数14→7，缩减至约一半高度，保留多行输入、链接文字及原自动保存流程。不会截断原备注。
- 修复新建/重命名级别弹框过早释放输入控制器的问题，控制器随弹框组件销毁。
- 客户新建级别后进入新级别；新级别为空时清空原客户选择和备注/跟进扩展面板，显示详情占位。
- 客户、订单列表加载完成后，选择状态与当前结果协调：原选择仍在列表则保留；否则选中第一项；空列表则清空详情及扩展。回调读取当前路由的最新结果，避免快速切换时旧列表覆盖新选择。加载中保留状态，避免短暂重新加载时闪动。
- 客户级别继续由二级目录（手机横向导航）单选。移除桌面顶部标签多选、更多标签、标签删除入口和手机额外标签筛选。旧的内存标签筛选不再参与列表查询，避免隐藏的A+B交集导致空列表。
- 客户、订单详情都移除标签展示和增删选择区；订单侧栏移除标签及标签管理，手机订单导航改为全部/重要订单/一般订单的单选。订单客户筛选、状态、优先级、财务、文件等功能保留。

## 数据兼容

不删除历史标签定义或关联，不修改数据库schema、后台接口、依赖及版本号。保留仓储标签API、旧订单标签路由和原客户级别关联标签映射供兼容、导入、同步及历史读取；界面不再提供这些多标签选择。任务和文件自身的标签功能不受影响。
