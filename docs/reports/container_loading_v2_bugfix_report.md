# 装柜模拟 V2：容量、未装处理及拖动修复

修复日期：2026-09-06；发布校验与启动：2026-09-07。

## 修复内容

1. 修正理论容量和实际装柜使用的间隙计算。原来每件货物都包含尾端间隙，使 2900 mm 货物加40 mm后无法进入2900 mm分节。现在只计算相邻货物之间的间距：`n * size + (n - 1) * gap <= available`。
2. 保存按钮固定在编辑栏底部，滚动分节时始终可见；保留 Ctrl+S。确认提示条上移，避免遮挡保存按钮。
3. 增加“处理未装”入口，逐项显示分节、货物、设置数量、已摆放和未装数量。设置已更改时要求先重新计算；计算后可返回调整或确认保留未装数量。确认不会把未装货物伪装成3D已装货物；确认标志随方案持久化。
4. 普通拖动场景空白处改为直接平移，物体随鼠标方向移动。Alt+拖动仍可旋转，Shift+拖动可从货物上方整体平移，滚轮缩放。直接拖动货物的坐标换算和碰撞限制保留。

## 计算回归

测试规格：WPC 2900×160×120 mm；分节2900×2200×2690 mm。

| 间距 / 数量 | 理论容量 | 实际已装 | 未装 |
| --- | ---: | ---: | ---: |
| 0 mm / 286件 | 286 | 286 | 0 |
| 10 mm / 286件 | 260 | 260 | 26 |
| 40 mm / 180件 | 187 | 180 | 0 |
| 40 mm / 200件 | 187 | 187 | 13 |

40 mm 下排布为1列×11排×17层。实际货物尺寸、方向、禁止堆叠、混装占用和整柜剩余载重仍可能降低实际装载量；真实超长货物不会强行装入。包间距不是箱壁预留空间的独立参数，实际装柜仍需现场核对。

## 数据与修改范围

没有数据库迁移、删库或改写用户方案。复用现有 `manualQuantityOverride` 保存确认决定，设置数量与实际3D组分别保留。仅修改装柜模块、相关测试与文档，未改动其它业务模块。
