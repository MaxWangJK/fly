# 装柜 V4：实时计算、托盘叠放与空间顺序

## 本轮修改

- 移除分节“自动装柜”按钮。新增货物、修改数量/排布/位置/方向、移除货物及调整分节时立即重算；无需额外点击确认开始计算。修改所在节的排布会替代该节原来的手动位置，其它节保持不变。
- 托盘默认允许堆叠，数量2优先竖向叠放，再考虑横向占用；箱体高度和载重仍为硬约束。旧版本默认关闭堆叠的托盘方案打开时修正一次，新版明确关闭堆叠的选择通过快照版本标记保留。
- 托盘靠左/右且存在剩余空间时：01为侧面、02为上方。居中时：01左侧、02上方、03右侧。各自标注长×宽×高；无实际高度、禁止堆叠或空间宽度为0时不伪造空间。
- 用户允许的长度悬出规划阈值改为1000mm（1m），包含恰好1m。超过1m仍不扩展。保留可关闭选项及现场支撑/承重确认提示；这不是结构安全或实际装柜认证。
- 超出尺寸/载重的数量仍显示为未装，实际3D数量不造假，保存入口保留。
- 失效空间关联保留，不因自动重算悄悄清零原数量。新版本没有数据库结构迁移或删除用户数据。
