# 装柜模拟 V5：货物配色与递归剩余空间

## 本次交付

- 不同货物采用可区分的柔和配色，同一种货物在方案内保持一致；列表、剖面图、3D 与图例使用同一颜色。旧方案中相同或近似的默认颜色会在打开时区分，保存时保留。
- 保留用户输入的每排数量、层数和合计，不会为了填满空间而改为推荐值。
- 放货后，从实际占用的长方体中扣除货物，计算互不重叠的剩余空间。上方空间优先编号，之后显示侧面空间；每块显示长、宽、高以及来源空间。
- 剩余空间可以不放货，也可以继续选择货物；再次放货后仍可继续拆分。保存、重新打开以及重新计算保留分配关系。
- WPC 位于托盘右侧时，默认贴右边界摆放，减少每排数量后，托盘与 WPC 之间的间隙会单独显示。
- 剖面显示实际货物颜色、堆放层次与剩余空间编号。修复空间卡片增多、切换方案时的滚动布局错误。

## 数据与计算约束

- 没有删除数据库、修改数据库版本或重做 CRM、订单、任务、日历、四象限。
- 子空间使用包含边界的稳定标识。上游货物改变导致旧子空间消失时，原分配和数量保留并提示重新选择，不自动挪到另一个位置，也不将未放入的数量计入已装。
- 上方空间必须有允许堆叠的货物支撑；保留既有 1m 长度悬出规划选项。这不是实际承重或结构安全认证，装货前仍需核实支撑、包装与载重。
- 很窄的真实余隙也会展示尺寸；能否放入货物取决于所选货物尺寸，不虚报满柜。
- 初始托盘空间是父级分配区域，编号较后的空间是它的剩余区域；两者不能相加作为总可用体积。

## 验证场景

- WPC 6 × 18 与 3 × 18、PVC 4 × 10：数量保持不变，上方与侧面余量不重叠、不超出箱体、不与现有货物相交。
- 从剩余空间继续放入 PVC：生成下一层可用空间。
- 改变原 WPC 层数：旧子空间分配保留为未装，不静默丢失。
- 不同货物颜色区分，同一种货物颜色一致，保存后重开以及重新计算保持一致。
