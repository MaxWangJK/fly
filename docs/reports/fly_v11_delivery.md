# Fly V11 交付报告

日期：2026-09-23；版本：1.0.11+17。

## 本轮实现

1. **CRM**：快捷跟进完成/撤销、两秒反馈、操作来源和日期快照、后续修改保护。保留当前级别创建、规范化同名拦截和来源文本输入。
2. **标签**：Customer / Order / Note / Task 独立作用域，迁移保留历史关联；客户/订单赋标签增加域校验；全局标签搜索按域定位。
3. **Files**：移除客户业务标签的自动展示，客户/订单关系可点击；沿用紧凑图标/单行列表、缩略图及预览；卡片普通拖动可发起 Windows 原生拖出，长按保留内部移动。
4. **Calendar**：单日投影、完成日显示、月/周视图、完整日期任务列表滚动/鼠标拖动、主题取色。保留 Tasks Today 的区间逻辑和逾期逻辑；日历/四象限任务右键也支持顺延。
5. **Review**：历史日期选择器（上限今天）、四块内容、底部加大的今日总结；保留自动保存和历史内容。
6. **Notes**：自然 Enter 拆块、Shift+Enter 换行、标题回正文、待办连续输入/空行退出、Hover 加号/拖动柄；保留现有列表、排序、标签、Markdown 快捷键及媒体。
7. **导航/空状态**：工具显隐持久化及安全路由回退；空业务页的创建入口和全局搜索提示。
8. **装柜**：待装货物拖回最近节时尝试合法吸附；独立可交互剖面与 3D 共用坐标，保留手动位置、超限提示、撤销重做和保存。
9. **授权/语言**：保留既有 72 小时离线试用、机器码、签名授权、私钥隔离；新交互提供中英文文字，不翻译用户业务数据。

## 数据库迁移

schemaVersion **14 → 15**。增加快捷跟进元数据与标签 scope，调整标签唯一键，按实际关联克隆其他域标签；保留客户级别标签原 ID。迁移为事务，完成前检查外键，失败回滚，不删库。

详细说明：`docs/architecture/fly_v11.md`。本轮没有启动应用，尚未在用户数据库上执行迁移。

## 重要限制与注意事项

- 编译成功不等于运行时验收完成；重点人工确认首次升级、跟进撤销、原生拖放、剖面拖动、通知和授权。
- 通讯应用/WhatsApp 是否接受拖入取决于具体客户端和 Windows 权限等级；不保证不支持标准文件拖放的程序能够接收。
- 文件 PDF/Office/视频没有新增内置播放器或渲染器，继续提供类型/元数据及系统默认程序打开；图片有内部预览和缩略图。
- 装柜只做规划，吸附考虑已有几何碰撞/堆叠约束，不替代实际承重、支撑及装卸安全判断；超限仍需要确认。
- 撤销快捷跟进采取保守策略：操作后有客户修改也可能拒绝自动回滚，避免覆盖后续数据。
- 已升级到 schema 15 的数据库不要直接用旧版程序打开；回退必须恢复完整备份。
- 安装器工具为当前机器上的 Inno Setup 7；若编译器提示 Non-commercial use only，正式销售前需自行确认工具商业使用授权。
- 现有离线授权不宣称能够抵御本机管理员或虚拟机快照还原；保留既有安全边界。
