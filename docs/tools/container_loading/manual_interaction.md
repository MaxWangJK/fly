# Manual interaction

- Left-drag empty scene: orbit camera.
- Mouse wheel: zoom.
- Shift + left-drag: pan.
- Left-drag cargo group: move on the loading floor plane.
- Right-click cargo group: rotate X/Y/Z, duplicate or delete.
- Toolbar: reset, top, side, front and 3D views.
- Ctrl+Z / Ctrl+Y: undo and redo add/move/rotate/delete state.

Moves snap to a 50 mm grid and to nearby container/group surfaces within 30 mm. A candidate outside the container or overlapping another group receives a red outline and is restored when released, so invalid transforms are never saved.

Selected positions are shown in metres while stored values remain integer millimetres. Screenshot export captures the current 3D view as PNG; Copy Summary produces a concise message suitable for WhatsApp.
