# V2 场景

保留 Flutter CustomPainter 的原有正交 3D 投影与鼠标交互。cargoBoxFaces 显式包含六个四边形（等价十二三角形）；根据相机方向选择可见面，统一货物材质并在顶/侧面调明暗。

V1 缺面根因是永远只画 +X/−Y/+Z 三个固定面。V2 正负视角覆盖六个面；货物按相机深度绘制，拾取用实际可见面的投影路径。

地板根据真实 Section 起止位置显示分界线，下方显示 Section 编号和长度；末尾单列未分配长度。当前节高亮，其它节降低亮度。

保持组级批量绘制与 AABB 碰撞。托盘底边加粗。手动拖动须满足 Container 和所属 Section 两重边界，非法 Drop 回退。高度可通过选中面板 +/-50 mm 或输入 Z 调整；支持 X/Y/Z 直角旋转、撤销重做。

鼠标：普通拖动空白处按屏幕位移平移，向右/向下拖动即向右/向下移动。Alt+拖动旋转，Shift+拖动整体平移（即便起点在货物上），滚轮缩放；直接拖货物仍为货物移动，通过投影逆变换换算真实坐标。

截图是自动化界面验收渲染，实际 Windows Release 另行运行验证。不把批量绘制结构等同于已测得固定 60 FPS。
