# 货物库

CargoPackage 包含 ID、名称、包装类型、整数毫米尺寸、整数克重量、稳定颜色、可选每节默认数量和审计时间。删除使用 deletedAt。门扇输入为高度/宽度/厚度，内部保存在 length/width/height。

货物编辑器提供八种低饱和颜色，支持 cm/mm/m 转换、编辑和复制规格。数量可留空；添加到分节时预填默认数量，否则预填 1。内置 WPC 默认 286。

放置方向、位置、底部和堆叠属于 SectionCargoEntry。数据库原有旋转和 stackable 字段为旧算法兼容而保留，新编辑器不将它们作为货物固有属性编辑。

每个 Plan Entry 保存货物规格快照，后续库编辑或软删除不会改变已经保存的方案。
