# 用户数量覆盖

数量超过本节理论容量时，提示系统计算与用户数量，并提供取消/修改和“仍按 N 继续”。确认后 entry.manualQuantityOverride=true，quantity 保持用户值，重复计算不再次阻止、不自动减回理论值。

UI 保持“用户覆盖理论容量”提示。几何算法只生成可以按准确尺寸摆放的货物，设置数量与已摆放数量分别保存/展示；无法按尺寸表示的数量列为“未装（不计入已装）”。底部“处理未装”列出每节货物的设置、已装和未装数量。设置过期时先重新计算；计算后可返回调整或确认保留未装数量。确认仅记录业务决定（manualQuantityOverride），不生成虚假几何，也不重新标记已装结果为过期；保存方案后此标志随数量一起保留。未装货物仍需另行安排。

载重限制仍参与计算。覆盖标志不会跳过载重和碰撞校验。
