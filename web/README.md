# Fly 官网

这是独立的 PHP 官网，使用 `public/` 作为唯一对外目录。`src/` 包含页面、方案、订单和设备授权基础。网站使用品牌中性的账户与购买说明，没有接入支付服务。数据库、日志、配置和私钥不能公开或提交。

## 当前状态

- 已完成中文响应式官网，使用 Fly 实际桌面界面的演示截图。
- `src/catalog.php` 配置基础版和高级版的模块清单；价格由环境变量提供，未配置时显示“价格待公布”。订单会保存购买时的金额和模块快照。
- 当前没有支付适配器。购买接口保持关闭，即使设置销售开关也不会开启；支付通知接口返回 410，不修改订单、不发放授权。返回页仅提供提示。
- 已实现已付款账户按设备码领取 Ed25519 授权密钥，最多 3 台不同设备；同一设备可重复查看。密钥使用现有 Fly 公钥对应的签发私钥生成。
- 账户登录尚未实现。设备授权接口要求服务端会话中已有经过验证的 `fly_verified_user_id`，因此对普通访客保持关闭。**不要通过浏览器参数或表单设置该会话值。**
- 当前 Fly 桌面端的授权校验器只校验设备码、签名与到期时间，尚不校验 token 中预留的 `sku` / `modules`。基础版和高级版正式销售前，必须完成桌面端模块限制和升级策略；现在不应开启 `FLY_SALES_ENABLED`。
- “永久买断”以授权 token 的 `9999-12-31T23:59:59Z` 表示；桌面端已有校验器可以识别，但仍应在正式发布包上实测激活。换机规则尚待确定，目前达到 3 台后需人工售后处理。

## 本地预览

需要 PHP 8.2+，启用 `openssl`、`pdo_sqlite`、`sodium`。在 `web` 目录运行：

```sh
php -S 127.0.0.1:8080 -t public public/router.php
```

访问 `http://127.0.0.1:8080/`。运行核心流程检查：

```sh
php tests/smoke.php
```

Windows 官方便携 PHP 需要在 `php.ini` 启用上述扩展。本机验证使用的是临时目录中的 PHP 8.5.11，没有将运行时放入仓库。

## 上线前配置

1. 确定账户与支付服务后，实现独立适配器；完成服务端身份验证、支付签名验证、金额和币种核对、幂等、退款与异常恢复。当前不具备这些支付能力。
2. 配置可公网访问的 HTTPS 域名。支付返回页只显示提示，不能依据浏览器跳转发放授权。
3. 把当前桌面安装包**实际使用的** Ed25519 私钥安全转移到服务器，设置 `FLY_ISSUER_PRIVATE_KEY_FILE`；公钥必须与 `issuer_public_key.txt` 一致。若换签发密钥，需要重新构建桌面应用并考虑已发授权。
4. 接入账户登录并在服务端完成用户身份校验和安全会话绑定，然后再设置 `$_SESSION['fly_verified_user_id']`。登录成功时应调用 `session_regenerate_id(true)`。
5. 完成桌面版模块授权校验，确认基础版无法使用高级版模块；确定升级、换机、退款和售后规则。
6. 配置 `FLY_PRICE_BASIC_CENTS`、`FLY_PRICE_PRO_CENTS`，明确币种并完成测试环境与真实小额交易验收。当前 `paymentReady()` 固定返回 false；完成适配器与回归测试后才可以设计开启销售的流程。

`FLY_DOWNLOAD_FILE` 可配置为服务器上的正式安装包绝对路径；未配置时 `/download` 返回 404。只有验收通过的安装包才应开放下载。

## 验证范围

`tests/smoke.php` 验证购买关闭、匿名身份保护、价格快照、未付款账户拒绝发钥、重复设备取钥、授权签名和三设备上限。测试使用临时签发密钥与内存数据库；已付款状态由测试夹具写入，不代表已实现真实付款。此次变更没有删除或迁移生产数据库，也没有部署公网网站。
